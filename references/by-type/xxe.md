# XXE 与隐式 XML 入口

适用信号：XML/SOAP、sitemap、SVG、Office 文件或 XML 中间处理

## 检查与最小实验

先证实 XML 实际被解析，以及解析发生在请求线程还是后台任务。除了显式 XML API，还检查正常导入/抓取流程中确实使用的 XML 文件；不要在所有接口强行切 XML。

使用无敏感内容的受控实体标记区分：文件被下载、实体被解析、实体内容被业务消费。外部实体、参数实体、XInclude 是不同机制，只有对应解析路径成立时才进一步核对。唯一回连应关联后台任务，排除普通抓取器。

## 证据与反例

HackerOne #312543 的历史入口是 Site Audit 下载并解析 sitemap，而非直接提交 XML 的 API；因此需要跟踪异步消费者。OAST DNS 单事件、语法报错都不能推断本地文件读取。XML 实体扩展也不自动证明 RCE。

## Agent 行为

不使用实体爆炸、超大文件或真实敏感文件外带。若任务只支持回连归因，按该能力报告；读取文件的验证需要另有获准的非敏感参照。

Office类上传先核对真实包结构、成员路径与处理器，不从扩展名或帖子所称DOCX推断sharedStrings.xml被解析。用正常小型文档和合成标记关联上传、转换任务及具体XML消费者，观察失败要区分成员未被消费、实体禁用、格式无效和回调通道失效。换成FTP等协议产生回连也只按已归因的解析/连接能力记录，不补造文件外带；协议与接收端需明确获准。

带外接收端返回400与是否收到请求是两个观察。若异常请求行或解码失败日志含合成标记，保存原始协议、接收时间、任务关联和解析失败原因，不把接收拒绝自动记成无回连，也不从受控端自写日志直接证明目标文件读取。读取边界另需已获准合成文件/实体和消费者证据；不为了规避换行/URL限制将生产文件内容外带。

图片元数据是隐式XML入口候选：先识别实际图片格式、元数据段及处理库，跟上传→提取/转换任务→XML解析器→资源请求的具体路径。文件中存在XML文本不证明处理器解析实体；普通缩略图抓取也可能产生回连。以小型正常图片、非秘密合成元数据和已获准受控资源分别确认解析与取址能力，再转[SSRF](ssrf.md)核对目的地限制。源帖“本地DTD→云凭据→接管”只有链名，没有各边证据；不据此读取云元数据秘密或推导云权限。

XML声明的encoding、HTTP层声明、实际字节编码与WAF/解析库的解码阶段分别保存。UTF-7字符串只是具体解码差异的假设：先在获准隔离样例证明处理器支持该编码且实体路径可达，再观察受控标记；改声明不自动转换字节，也不代表服务端启用了外部实体。[XML 1.0编码条款](https://www.w3.org/TR/xml/#charencoding)要求处理器支持UTF-8/UTF-16，不保证UTF-7（2026-10-09核对），因此不继承“轻易绕过所有XXE过滤”的源帖结论。

## 外部实体协议与Expect扩展的条件

XML写出expect://id只产生外部实体协议候选。[PHP Expect包装文档](https://www.php.net/manual/en/wrappers.expect.php)明确该包装默认未启用，需安装PECL Expect扩展；其用途是进程交互（2026-10-09核对）。外部实体启用、解析器实际资源加载器、底层包装注册和进程执行权限是不同前提，XML字符串或DOCTYPE存在不能证明任意环境RCE。

优先获准配置/依赖清单与隔离无害实体观察，保留XML字节、实际解析调用、扩展/版本和解析错误。源示例ELEMENT声明与根标签不同、用户/密码含反引号，仅示例片段而无解析回执；不用命令协议补证，不安装Expect或执行id，不从文件/网络实体能力直接升级命令执行。

## 媒体类型过滤后的解析错误与实体能力

关联实际请求字节/长度、声明类型、后端选解析器的方式、组件/版本和实体策略，以及正常XML/合法拒绝基线。到达解析器、请求被接受和真正启用外部实体是三层独立事实；需已有配置/日志或获准隔离合成标记区别。不要把400称XXE成功，不读取系统文件、发metadata请求或运行源片段补证。

## 音频元数据中的XML与升级后失效的防护

[Sonar原始分析](https://www.sonarsource.com/blog/wordpress-xxe-security-vulnerability/)将CVE-2021-29447绑定WordPress5.7.1之前、PHP8及媒体上传权限：WAVE的iXML块经getID3进入SimpleXML，LIBXML_NOENT显式启用实体替换；旧代码在PHP8跳过实体加载禁用，默认安全假设与显式flag发生冲突。该修复恢复加载限制（2026-10-10核读技术/权限/修复段）。

审计多媒体容器→元数据→XML解析器→显式选项及实际加载器，升级/弃用分支不能只读注释。解析结果未展示与盲观测通道分别取证，看到author登录页不证明有上传能力或实体已解析。只读获准源码和合成制品轨迹，不生成活动WAVE/DTD、上传、读配置秘密或建立外传；历史条件不推广为当前所有WordPress/PHP8均可利用，来源视频未观看。
