# 认证与会话漏洞

## 登录与暴力破解
- 无验证码/验证码可复用/可绕过 → 撞库风险（仅自建账号测试，不爆破真实用户）
- 用户名枚举：注册/登录/找回密码响应差异（"账号不存在" vs "密码错误"）

## 密码找回
- 验证码回显在响应中
- token 可预测（时间戳+固定 salt）、可爆破、未绑定账号
- 步骤可跳：直接访问设置新密码接口
- 短信/邮件轰炸：验证码发送接口无频率限制

## 会话管理
- Session 固定：登录前后 session 未更换
- 会话未失效：改密/退出后旧 token 仍可用
- Token 泄露：URL 参数、日志、Referer、前端 localStorage 明文

## JWT 攻击面
- alg none 绕过：`{"alg":"none"}` + 空签名
- HS256 弱密钥爆破（hashcat/jwt_tool）
- kid 参数注入：指向可控制文件（路径穿越/文件读取）
- 过期校验缺失/篡改 payload 不验签
- 测试仅对自己 token 操作，不伪造他人

## OAuth/SSO
- redirect_uri 校验缺陷（开放重定向）
- state 参数缺失 → CSRF 登录
- code 未绑定用户/可重放

## 验证边界
- 所有尝试仅限自建测试账号
- 不进行大规模字典爆破、不利用撞库数据
