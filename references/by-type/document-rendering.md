# 文档导出、渲染与后台消费者

适用：HTML/Markdown 转 PDF、简历/报表导出、预览、电子文档校验、上传后解包或转换。记录输入入口、队列/任务 ID、消费者、渲染引擎及版本/启动参数、输出资源和执行身份；未知项不能由扩展名补出。

## 分清四种能力

| 观察 | 可支持的事实 | 后续必要判断 |
|---|---|---|
| 浏览器弹窗或页面标签变化 | 当前浏览器上下文的行为 | 输入是否可由另一主体投递，是否违反渲染规则；不推出后端能力 |
| PDF 中出现 HTML 排版 | 文档流水线处理了格式 | 哪个进程渲染，是否允许主动内容或外部资源；不自动算 SSRF |
| 独特外部资源标记被请求 | 某组件请求了标记 | 与任务和后端归因、目的地规则、是否仅为正常外链抓取 |
| 导出含受控文件标记 | 相应文件内容进入输出 | 文件归属、消费者权限、是否越过预期根目录或共享边界 |

## 最小验证

优先读取已有消费者日志、配置和产物元数据。若获准，可在隔离环境用单个普通标记分别观察格式处理、唯一资源请求和输出；每个能力独立给结论。远程资源回显需遵循项目指定方式及 [SSRF](ssrf.md) 标准，不能把 403 页面或作者截图解释成读取内网敏感信息。

文档可能是容器：分别检查上传文件名、MIME 解码、归档条目路径、最终落盘路径和清理顺序。只有临时保存成功而未越出允许目录时不确认路径穿越；错误退出后仍留下的受控文件要结合写入顺序核对，不能认为“处理失败”等于无副作用。

文件读取/解压验证仅用获准隔离目录中的自建标记，不读生产秘密、不覆盖应用文件、不写入任务调度目录或执行脚本。写操作异常后先核对残留资源，再按已有许可清理。

## 版本与退出条件

不能从 PDF 的 Producer 字符串推断确切运行版本、参数或漏洞。wkhtmltopdf 的 [官方参数说明](https://wkhtmltopdf.org/usage/wkhtmltopdf.txt) 与实际启动参数需一起核对；历史文章的默认本地文件访问描述不自动适用于当前部署。

只有达到 [技术确认](../verification.md) 和 [影响/收录](../impact-and-acceptance.md) 门槛才形成候选；其余保留已证明的有限能力。对应研究见 [K09–K10](../research/crawl-xz-patterns.md)，路径处理继续读 [路径穿越](lfi-path-traversal.md)。
