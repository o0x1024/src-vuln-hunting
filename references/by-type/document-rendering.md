# 文档导出、渲染与后台消费者

适用：HTML/Markdown 转 PDF、简历/报表导出、预览、电子文档校验、上传后解包或转换。记录输入入口、队列/任务 ID、消费者、渲染引擎及版本/启动参数、输出资源和执行身份；未知项不能由扩展名补出。

## 分清四种能力

| 观察 | 可支持的事实 | 后续必要判断 |
|---|---|---|
| 浏览器弹窗或页面标签变化 | 当前浏览器上下文的行为 | 输入是否可由另一主体投递，是否违反渲染规则；不推出后端能力 |
| PDF 中出现 HTML 排版 | 文档流水线处理了格式 | 哪个进程渲染，是否允许主动内容或外部资源；不自动算 SSRF |
| 独特外部资源标记被请求 | 某组件请求了标记 | 与任务和后端归因、目的地规则、是否仅为正常外链抓取 |
| 导出含受控文件标记 | 相应文件内容进入输出 | 文件归属、消费者权限、是否越过预期根目录或共享边界 |

## 最小验证

优先读取已有消费者日志、配置和产物元数据。若获准，可在隔离环境用单个普通标记分别观察格式处理、唯一资源请求和输出；每个能力独立给结论。远程资源回显需遵循项目指定方式及 [SSRF](ssrf.md) 标准，不能把 403 页面或作者截图解释成读取内网敏感信息。

文档可能是容器：分别检查上传文件名、MIME 解码、归档条目路径、最终落盘路径和清理顺序。只有临时保存成功而未越出允许目录时不确认路径穿越；错误退出后仍留下的受控文件要结合写入顺序核对，不能认为“处理失败”等于无副作用。

文件读取/解压验证仅用获准隔离目录中的自建标记，不读生产秘密、不覆盖应用文件、不写入任务调度目录或执行脚本。写操作异常后先核对残留资源，再按已有许可清理。

## 版本与退出条件

不能从 PDF 的 Producer 字符串推断确切运行版本、参数或漏洞。wkhtmltopdf 的 [官方参数说明](https://wkhtmltopdf.org/usage/wkhtmltopdf.txt) 与实际启动参数需一起核对；历史文章的默认本地文件访问描述不自动适用于当前部署。

只有达到 [技术确认](../verification.md) 和 [影响/收录](../impact-and-acceptance.md) 门槛才形成候选；其余保留已证明的有限能力。对应研究见 [K09–K10](../research/crawl-xz-patterns.md)，路径处理继续读 [路径穿越](lfi-path-traversal.md)。

SVG中的外部图片引用是否会取址，取决于实际消费方式、处理模式、渲染器和安全策略。直接导航、object/iframe、img/CSS图像、服务端转换和安全扫描分开记录；[SVG Integration处理模式草案](https://svgwg.org/specs/integration/#secure-animated-mode)（2026-10-09核对）为安全图像模式限制外部引用，不代表所有当前客户端/转换器已实测。只用获准接收端与一次性无害标记核对实际请求，关联任务和触发窗口；没有请求保留禁用引用/缓存等反例，收到请求也可能来自代理、预取或扫描。来源IP不能识别真实访问者，不以真实用户访问收集IP来补证；后端请求边界继续按[SSRF](ssrf.md)判定。

TeX/LaTeX导出先固定真实引擎、输入模板、加载宏包、编译身份、工作目录与产物消费者。源文列出的input/include/verbatiminput仅是相应读取路径候选，需跟文件搜索/限制和实际输出；导入普通tex与逐字展示任意字节不同，宏包缺失或编译报错不补文件读取。只在隔离目录用自建普通标记区分原始内容进入产物、排版差异与错误。PDF中的URL/href还须跟最终链接表示和阅读器动作；含javascript文本不自动是浏览器XSS，更不能推出编译进程执行命令。独立核对读取、外链、浏览器脚本和进程能力，不编译源帖载荷或读取生产系统文件。

## 导出数据查询与产物授权

报表/PDF导出同时跟数据选择、后台任务和产物下载三条权限边。用两个自有身份与合成对象，关联请求的email/ID/过滤条件、实际查询主体、生成任务ID、产物归属和下载读者；后台服务账号能读全量数据不代表发起者有权导出。改变ID、导出成功或公开下载链接不自动是越权，合法分享/授权报表作反例。数据来自数据库也不自动提供SQL注入路径：先有实际查询构造/绑定依据才按[SQL注入](sql-injection.md)选择无害对照；渲染网络能力继续按[SSRF](ssrf.md)另证，不导出真实用户数据。

## CSV字段到电子表格公式

聊天内容导出为CSV，再由另一个用户打开，是导出者/数据作者/消费软件之间的信任边。保留原文本、CSV原始字节、列分隔/引号、最终单元格类型、软件版本/配置及实际提示。[OWASP CSV Injection](https://community.owasp.org/attacks/CSV_Injection)说明不可信字段可能成为公式，分隔符可改变单元格边界，保存/重开也可能改变转义效果（2026-10-09核对）。只用无外部引用的合成算术标记在隔离材料中核对文本与公式解释，排除本来允许的公式字段；旧DDE/calc例子中的警告、用户动作和执行能力不能推广到当前Excel/Calc，也不执行命令、加载外链或要求他人忽略警告。

## 网页截图服务的网络与本地文件输入

URL截图功能分别识别前端导航、后台浏览器/渲染进程、其运行身份及最终产物；localhost网络访问与file协议读取是不同能力。截图出现类似系统文件文本，仍需关联输入、任务/产物与实际读取进程，排除纯文本回显、自建页面或不同环境；不能从一张遮盖域名图推所有文件可读或系统密码已获得。

优先获准配置、日志及隔离目录的自建无害文件，对照允许网页截图和实际协议/根目录边界，保持最小读范围。普通账户列表、真实凭据和命令能力分别判断；不读取生产系统文件、探测内部管理站点或扩大截图尺寸来采全量敏感内容。

## PDF对象边界与脚本和表单动作

PDF注入图应沿生成库的字符串/annotation URI、括号/反斜杠转义、对象边界、产物与具体阅读器消费者追踪。[作者研究的理论与方法](https://portswigger.net/research/portable-data-exfiltration)区分结构控制、PDF JavaScript函数与SubmitForm动作（2026-10-09只核读相关理论/方法段落，未读取整份白皮书或视频）。PDF损坏、PDF弹窗、表单请求和文档内容被提供是不同证据。

## 导出后缀拼接与HYPERLINK的值及链接

旧图声称CSV导出给可疑输入追加-1会阻止公式，而加字符串拼接可恢复HYPERLINK；这是最终单元格表达式候选，未给实际导出字节、软件版本或点击记录。服务端加后缀不是把单元格变成文字，须核对完整表达式、运算优先级、数值/字符串转换、CSV引号与导入类型。

[LibreOffice HYPERLINK说明](https://help.libreoffice.org/latest/en-US/text/scalc/01/04060109.html)区分显示/返回值和链接目标，并给拼接后点击打开链接的例子（2026-10-09核读相关段）。不能把显示CLICK_ME#1等同于各软件都导航同一URL，更不把链接打开、公式求值、网络外带及系统命令执行合并。只在隔离无外部引用的合成文本/算术材料中分析表示，记录真实消费软件和必要用户动作，不加载源外链、执行DDE或要求他人打开CSV。
