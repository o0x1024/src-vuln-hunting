# PC 客户端与本地服务

触发：授权 Windows/macOS 客户端、安装包、更新器、本地监听/IPC 或远程输入链。先保存产品/版本/签名、OS、进程与服务权限、配置、攻击者初始能力和受害者交互。小米专属受理限制读 [MiSRC §4.6](../policies/xiaomi-misrc.md)，不得移植到其他项目。

## 有依据的验证分支

| 线索 | 最小对照 | 有效结论与反例 |
|---|---|---|
| localhost 服务、IPC、URL handler | 低权限测试调用者/受控网页与合法客户端对照，核对来源/身份/消息校验和实际资源状态 | 本地监听不是互联网暴露；关键在无权主体是否获得受保护能力 |
| 更新器/高权限 helper、文件解析 | 跟远程或普通用户可控输入到验证与高权限操作；仅在批准隔离环境用无害标记 | 已能改安装介质、调试配置或同权限文件后执行同权限代码，不自动获得新的权限边界 |
| WebView/Electron/桥接 | 关联实际不可信输入、渲染上下文、桥与原生效果；保留原版配置 | 风险配置不是利用证明；技术成立与小米当前 Electron 类排除分别记录 |
| 通信、账户或设备操作 | 用两个受控身份核对 token/对象绑定及实际结果 | 根因在服务端就按 Web 规则；不能把只影响自身流量的 MITM 写成所有客户端接管 |

保持本地准备与攻击前提分离，记录 DLL/配置/目录修改究竟需要什么初始权限。远程性、额外权限、用户交互和真实业务影响分别证明；批量/持久控制只作为已有证据的影响分析，不实施持久化或扩大目标数量。

## 原生解析器与内存错误

有实际文件、消息或协议输入进入本地二进制时，在获准隔离环境固定产品哈希、OS/架构、运行配置与攻击者权限。先保存正常样本，再以有限变体定位稳定触发条件；记录最小输入、栈、崩溃位置及可用诊断器证据，跟踪长度/整数转换、对象生命周期或共享状态与错误的关系。

| 观察 | 应继续区分 |
|---|---|
| 长输入后崩溃 | 解析拒绝、资源耗尽、断言失败还是内存越界；不能直接标 RCE |
| 释放后访问、重复释放或格式化线索 | 实际调用路径、可控数据及诊断证据，不能按检查表名称定性 |
| 不稳定或只在调试环境出现 | 时序、构建差异、输入前提和观察有效性；阴性限定于已测条件 |
| 内存错误已证明 | 现实入口、受害交互、进程权限和额外安全影响仍需分别确认 |

最小崩溃与根因充分时可交付已有能力，不自动继续绕过 ASLR/DEP、加载恶意 DLL 或构造执行链。离线 Fuzzing 的运行次数、输入大小、进程资源和停止条件另设预算，不能把本地崩溃迁移成线上压力实验。

## view-source外层与内层URL权限

view-source:file形式包含浏览器包装层和内层文件URL。沿应用接收不可信URL、解码/解析、允许规则、导航/DevTools/原生加载API及实际文件读取主体逐层核对；只封禁字符串file前缀可能与后续解包不一致，接受包装形式也不代表普通远程网页取得本地读取能力。[Chromium 2026-03-31重新合入记录](https://chromium.googlesource.com/chromium/src/%2B/1f5d394c07145c007178a7ae65205b572d79c22e)描述的是DevTools的Target.createTarget/Page.navigate文件访问检查，之前有回退；该提交历史不能直接证明某发布版本或所有浏览器已修复（2026-10-09核对提交说明，未核对完整实现/发布覆盖）。

以明确获准的合成本地文件绑定进程权限、调用者能力和内容最终流向。研究者主动在本机地址栏查看已有文件、已控制DevTools或高权限配置与远程输入越过限制是不同前提；若读取位于客户端，不移植为服务器LFI。仅有包装字符串与黑名单描述时保留待核对消费者，不打开源示例系统文件。

## Windows进程主令牌与线程模拟身份

Windows的access token描述进程或线程安全上下文，不是Web Bearer字符串。[Microsoft令牌说明](https://learn.microsoft.com/en-us/windows/win32/secauthz/access-tokens)区分进程primary token与线程impersonation token，线程模拟时可使用客户端上下文（2026-10-09核读相关段落）。调试器中进程ID、父ID和Token地址不单独证明可取得或滥用权限。

从获准同版源码/既有脱敏诊断关联实际线程、SID、启用权限、限制与目标对象检查；父进程名字和notepad.exe标签不代替有效主体。读取句柄、复制/调整令牌、模拟身份和创建进程各有权限/动作前提，本次仅静态解释图，不调用令牌API或尝试提权。
