# 小程序身份、请求封装与业务接口

适用：获准的小程序包、客户端正常流量、登录/手机号绑定、签名封装或后端接口。客户端平台、版本、包来源及可用调试方式需明确；旧文章中的桌面版本、插件和解包工具不作为默认安装方案。

## 正常链路与身份矩阵

区分平台身份、应用账号、手机号、租户和后端会话；不要将客户端展示字段当成认证主体。用两个独立受控账号记录登录前、令牌兑换后、绑定/换绑后的权威身份，以及资源归属。

同一小程序的详情、列表、搜索、导出、下载、上传、后台视图可能有独立授权。根据正常流量或已获准源码建立关联，优先比对一个有具体线索的兄弟入口；详情接口拒绝不代表列表/导出安全。接口命名相似只构成线索，不做无依据拼接或批量取数。

## 请求签名与加解密

1. 从正常流量定位封装函数及调用点，记录 method/path、参数顺序、编码、空值/数组、body 原始字节、时间戳、nonce、会话和签名的依赖。
2. 使用脱敏受控样本离线核对序列化及签名输出。调试器/工具保存输入输出；Agent 不猜算法、密钥或缺失字段，也不通过执行来源里的未知脚本恢复签名。
3. 改变一个业务变量时重建当前会话所需动态字段。401/签名失败只说明请求未进入有效业务对照，不能当成对象授权正确，也不能无限重放过期样本。
4. 能解密、重算摘要、找到客户端常量或得到 200，不等于能控制其他身份。继续观察服务端是否独立绑定平台凭据、用户标识及会话，是否真正发生被禁止的操作。

## 最小证明与反例

| 线索 | 确认所需事实 | 不足以确认 |
|---|---|---|
| sessionKey/iv/密文或签名常量暴露 | 当前用途与有效性、攻击者可控边界、后端是否误信客户端身份；测试身份实际变化或受保护信息暴露 | 字段名称、无效示例密钥、仅解出自己信息 |
| 详情正常鉴权但列表暴露 | 未授权测试身份取得另一受控身份的私有标记，并排除公开分享/缓存 | 数量字段、空列表、公开昵称 |
| 下载地址与业务 ID 关联 | 受控资源、不同身份、实际下载内容与访问规则 | 拼出 URL、知道目录、200 登录页 |
| 修改手机号后返回 token | token 对应的权威身份及可访问资源，独立会话对照 | UI 手机号改变或服务端仍返回原账号身份 |

## 停止与报告

证据足够时停止，不复制历史文章批量遍历用户、暴力猜密钥、借用第三方账号或提升到管理员的步骤。真实敏感数据意外出现时按 [执行循环](../agent-execution.md) 限制采集。

报告列出客户端与服务端各自验证了什么、哪些封装步骤仅用于恢复正常请求、实际突破的身份/业务边界及当前 [收录条件](../impact-and-acceptance.md)。研究归纳和失败反例见 [K03–K04](../research/crawl-xz-patterns.md)，相关接口继续路由至 [访问控制](idor-access-control.md)、[认证](authn-session.md)、[文件上传](file-upload.md)。
