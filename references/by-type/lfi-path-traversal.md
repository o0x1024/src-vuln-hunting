# 文件路径、读取与包含

## 适用信号与前提

下载、预览、导出、模板选择、语言文件、解压及用户控制的路径参数。区分目录列表、任意文件读取、本地包含和执行，不把它们视为同一能力。

## 最小实验

优先使用获准自建且带唯一标记的文件，在已知允许/禁止路径边界做对照。依据真实平台路径规则选择有限的相对路径、编码或归一化变体，记录实际返回内容。

没有可用测试文件时，只选择明确获准的非敏感样例；不可默认读取应用配置、用户目录或源码。文件包含需要调用路径或解析证据；静态下载成功不证明 include 或执行。

## 确认与反例

确认服务器读取了原本不应读取的已知文件，或突破了指定路径/归属规则。路径字符串回显、错误栈、同名页面、软 404 和公开文件不是充分证据。

排除合法下载路径、符号链接/规范化的预期行为、默认模板回退、公开资源与缓存。数据截断或无法确认来源时待补证。

## 下一步、停止与报告

不进行日志投毒、会话文件写入、可执行上传组合或读取凭据来放大证明；不要枚举可达敏感文件清单。只清理获准自建样例。

报告记录规范化前输入、预期路径边界、样例归属与唯一标记、实际内容及尚未证明的包含/执行能力。遵守 [验证](../verification.md)。

## 调研补充：可执行检查点

- 分清 URL 路径规范化与文件系统路径越界。找出输入所在层、解码次数、基目录及实际读文件组件，再选择对应平台的分隔符/规范化检查。
- 用已知允许文件、已知不允许但获准测试的无敏感标记文件作对照；内容、哈希或权限边界证据优于单纯路径报错。
- 重复编码、一次性替换、前缀校验只在数据流有相应处理时形成假设。历史空字节技巧不能假定当前运行时仍有效。
- LFI 的文件读取与执行分开；归档提取越界也不等同于已经获得执行。没有安全参照文件时记录验证限制。

## 归档案例补充：落盘与执行分开

检查文档容器/归档条目最终解析路径及异常后的残留，不将字符串中的路径符号直接认定为穿越；隔离自建文件写出允许根目录的能力也不自动证明代码执行。见 [K10](../research/crawl-xz-patterns.md)。

文件参数还可能被目录 API、网络文件访问或 URL 下载器消费。用获准的自建文件、目录和受控远端分别区分内容读取、目录列举与网络访问，追踪实际 API/运行时配置。Windows 风格路径回连不能代替本地文件读取证明；某个 Java API 的目录行为也不能推广到所有 Java 文件接口。

错误或随机文件名仍返回相同内容时，先核对默认回退、缓存、前后缀拼接和实际消费者，不能据某次看似系统文件的响应确认任意文件读取。用两个内容不同的已知受控文件及不存在路径比较，并保存唯一标记/哈希；未解释的选择规则保留为待补证，不改读数据库配置或秘密文件来放大结果。

ZIP上传与PHP zip包装进入读取/包含时，固定ZIP扩展/运行时、实际存储路径、归档成员、包装字符串及最终文件API；归档可上传和成员可读不证明include执行。优先自建小型文本归档，在获准隔离调用中核对路径与标记，不上传执行代码。[PHP压缩流文档](https://www.php.net/manual/en/wrappers.compression.php)说明ZIP扩展注册zip包装，官方核对2026-10-09；具体目标能力未实测。

## 路径列表中的不同消费者

“目录穿越”图混入Windows/Unix路径、URL编码、HTML实体、命令解释器和cat命令字符串。先按真实平台、逐层解码、路径库及消费者区分文件定位与shell执行，不能把其中每项当等价路径或通用LFI。回显文字包含系统文件名不证明读取，带命令的输入需转[命令边界](cmd-injection-rce.md)且不从读取许可继承执行权限；优先合成文件路径与隔离解析，不读取系统文件或执行图中指令。

## PHP流过滤与包含执行分开

历史RT把已上传PHP文件经php://filter/convert.base64-encode读取称为LFI到RCE，没有响应或执行路径。[PHP流包装说明](https://www.php.net/manual/en/wrappers.php.php)将php://filter描述为打开流时应用过滤器的包装，[转换过滤器说明](https://www.php.net/manual/en/filters.convert.php)明确base64-encode转换流数据；转换读出的字节不是自动解码或执行代码（2026-10-09核对）。

分别记录实际文件API、read/write链、底层resource、当前运行时支持、可访问路径和输出消费者。优先获准无害文本与静态配置区分读取、内容转换、include/加载和执行，不从“先上传shell.php”继承上传或执行许可，不上传/运行脚本或读取真实配置；缺消费者与终态时不登记RCE。

## 浏览器包装URL与服务器文件读取

view-source:file的历史建议先转[PC客户端的内外层URL检查](desktop-client.md)。要判断LFI，需要证明文件由哪一进程/机器读取、不可信输入如何进入该读取API、原许可为何不允许以及合成内容实际交付给谁。浏览器能展示自己有权访问的本地文件，不等于应用服务器读取文件或普通网页能取走内容；包装形式通过前端黑名单只是中间观察。后端若把字符串当普通参数、浏览器拒绝内层协议或未发生实际读取，均不能按字符串定性。

优先获准配置/已有日志或隔离合成文本跟从写入到读取，区分普通日志展示、文件包含与解释执行，以及同机/容器路径差异。没有确证就保持缺口，不发邮件植入代码、投毒日志、读取系统邮件或调用phpinfo；LFI到RCE标题不是执行证据。

## Zip Slip与zip包装包含的不同边界

来源上传清单把zip包装访问归档成员标成Zip Slip，应纠正为两类消费者：Zip Slip涉及解压时归档成员路径逃出预期目录；zip包装则涉及运行时文件读取/包含如何定位归档和成员。允许ZIP、成员可读、成员被包含和代码被解释不是同一能力。

关联归档存储路径、解压API/规范化、成员名、落盘路径与后续文件API。沿已有zip包装条目用获准合成材料核对读取/包含，不把包含示例自动转成解压穿越证明；无需解压来源归档或投递可执行成员来理解此分类。

## 图片导入的本地来源到公开派生文件

图片导入入口接收picUrl并返回媒体ID，另一列表把ID映射到公开uploads路径，最后响应出现数据库配置文本，是三个需独立绑定的消费阶段。WeiPHP旧图里的media_id、返回834、列表834和.jpg制品提供这一线索，但不能把HTTP200或图片后缀直接算作读取成功；核对当前组件版本、入口身份、路径规范化、源文件读取/复制及派生字节。

以获准源码和隔离合成文件追踪本地路径是否允许进入导入器、复制时是否验证真实图像格式、生成文件由谁可读和多久保留。图片解码拒绝、限定来源根及受控下载鉴权是反例；仅返回ID或既有公开图片不证明私密数据泄露。文件内容到公开位置的发布边与穿越定位边分别写报告，不由数据库字段推出凭据有效或数据库可登录；不按旧图读取配置、下载秘密或创建生产制品。

## 过长UTF-8字节与页面显示字符

GlassFish旧正文显示À®等字符，原图请求目标却显示%c0%ae重复路径；页面Unicode显示、原始C0 AE字节及百分号请求目标不是同一表示。绑定原请求字节、代理解码/路径归一化顺序、鉴权路径和后端定位，版本与补丁缺失不能由Server标签或旧文件正文推断。

[RFC3629安全段](https://www.rfc-editor.org/rfc/rfc3629.html#section-10)把C0 AE这类过长序列列为非法编码并讨论解析差异风险（2026-10-09核读）。严格拒绝、只解码一次及前后同一规范路径作反例；把文字À®粘贴进URL不保证得到旧字节。只比较已有脱敏请求或隔离合成路径，不依旧图请求系统文件，不将一次旧成功概括为当前所有GlassFish可穿越。

## HTTP片段与ZIP成员分隔符

PHP ZIP包装语法中的#分隔归档与成员，而浏览器HTTP URL里的裸#开启客户端片段。[PHP流文档](https://www.php.net/manual/en/wrappers.compression.php)示例为zip://archive.zip#dir/file.txt；[RFC3986 §3.5](https://www.rfc-editor.org/rfc/rfc3986.html#section-3.5)说明片段在解引用前与其余URI分开（2026-10-09核读）。不能直接把包装字符串拼到浏览器查询中，便断言服务器获得完整成员路径；字段传输、百分号解码和最终文件API需逐阶段核对。

沿已有ZIP包装与包含条目记录实际请求目标/正文、字段值、解码次数、存储归档路径、成员、ZIP扩展和读取/包含消费者。编码井号被当数据传输、服务器解码后参与包装，与被上游URL解析截去不同；成员能读不等于代码执行，来源标2/2不补齐前半步骤。只分析脱敏请求/获准隔离文本成员，不下载来源归档、解压未知文件或上传执行成员。

## Windows UNC与远程URL开关的边界

Windows文件API可以把UNC路径定位到网络共享；它与http等URL包装不是同一消费者。[PHP file包装手册](https://www.php.net/manual/en/wrappers.file.php)列出UNC形式，并说明file包装不受allow_url_fopen限制（2026-10-09核读）。来源据此声称关闭两个URL开关仍可SMB包含，不能推广成所有平台/运行时或必然执行：当前文件API、路径接收、网络访问、共享权限及实际包含解释仍需证据。

从获准源码/配置追字段→转义/规范化→文件包装或本机路径→网络共享→读/包含消费者，区分读取文本与执行代码，也区分网络请求及潜在凭据发送。限定本地根、拒绝UNC、受限服务身份或网络不可达可作反例；单凭参数含双反斜杠不确认RFI。只使用隔离合成路径/脱敏回执，不搭外部SMB接收、捕获认证、访问真实共享或包含来源shell文件。

## 高权限备份对符号链接的定位

Node靶场拓扑图写直接备份root目录失败、备份指向它的symlink成功，仅提供路径检查与实际打开对象可能不同的线索，未给备份程序实现、有效身份或原始输出。setuid标志、程序名和最终文件路径不能独立证明以root运行，也不能把某个靶场链概括到当前所有备份工具。

在获准实现/隔离合成目录中比较输入路径、链接自身与最终目标、每级父目录、实际打开/遍历时点、服务身份和输出制品读者。检查与消费是否绑定同一对象，拒绝链接、限制规范根或不足目标权限作反例；复制/备份导致越权读取与写入任务文件后被高权限执行是两条独立链。保留现有脱敏权限/文件证据，不创建生产链接、读取root私密文件或替换计划任务。

## 日志写入、文件读取与解释执行的三段条件

旧帖把User-Agent写入访问日志，再通过文件包含参数调用PHP片段。分别核对代理/日志器实际保存哪些字节、转义与日志轮转，应用是否可读该文件，以及消费者是普通读取还是作为PHP执行。可读取日志不自动建立代码执行，日志路径、扩展名和请求参数名也不决定解释器。

优先获准源码、已有脱敏日志与隔离普通字符串追踪写入→文件对象→加载器→最终身份/效果；拒绝读取、仅文本输出、转义后不成程序均为反例。来源没有完整请求响应或当前部署前提，不按uname/系统文件片段补成功，不投毒真实日志、包含脚本、运行系统命令或读取凭据。


## nginx别名替换、目录边界与PHP静态字节

旧例用/assets../index.php对比/index.php的File not found与source code，建议替换img/js/assets等名称。关键是实际location匹配、alias/root、尾斜线、解码/规范化、文件系统边界及后续handler，不是名字或404指纹。[nginx alias文档](https://nginx.org/en/docs/http/ngx_http_core_module.html#alias)说明替换location并示例URI到文件映射，正则location还涉及捕获（2026-10-10核读alias段）。

由该映射语义推导候选边界：若匹配前缀与实际目录拼接留下上级路径，需核对最终文件位置及拒绝规则；这仍需目标配置/字节证据。PHP文件经静态路径读出与PHP解释执行不同，成功状态不等于源码。优先获准配置和不同内容的合成允许/越界/不存在文件对照，不读取真实源码秘密或向所有nginx404投路径。来源：[保存帖](https://x.com/i/status/1401259603845918722)。
