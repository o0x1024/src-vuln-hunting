# SSRF 技巧

## 触发点（找输入 URL 的地方）
- 图片/头像/文件下载、URL 预览/截图服务、PDF 生成、webhook 回调
- SSO/回调地址、跳转参数、XML 外部实体、代理接口、开放重定向
- 云函数/后端转发接口、导入功能（url 导入）

## 探测内网
- 回显型：直接看响应内容
- 无回显：时间差（连接内网端口耗时）、带外 DNS（dnslog/ceye）
- 目标：127.0.0.1/0.0.0.0/10.x/172.16-31.x/192.168.x/metadata IP

## 地址变形绕过
- 十进制/八进制/十六进制 IP：`2130706433`、`0177.0.0.1`、`0x7f000001`
- IPv6：`[::1]`、`[0:0:0:0:0:ffff:127.0.0.1]`
- 短域名：`127.1`、`0`、`0x7f.1`
- 解析差异：`http://evil.com@127.0.0.1`、`#`/`?` 截断、DNS 重绑定（第一次解析白名单域名，二次解析内网 IP）
- URL 解析器差异：curl 与后端解析不一致（URL 标准化差异）

## 协议利用
- file:// 读本地文件（/etc/passwd、应用配置）
- gopher:// 打内网服务（Redis 未授权写 crontab/SSH key、MySQL、FastCGI）
- dict:// 服务指纹探测

## 高价值利用链
- 云元数据：`http://169.254.169.254/latest/meta-data/`（AWS/阿里云/腾讯云）、`http://metadata.google.internal/`
- 内网服务探测：管理后台、数据库、消息队列、监控系统
- SSRF + 内网 Redis/Memcached 未授权 → 进一步利用（仅授权范围内验证）

## 最小化验证（铁律）
- 证明可访问内网即可：回显内网响应头/内容、DNS 带外、端口时间差
- 不真实攻击内网生产服务、不拖取元数据密钥明文入库

## 报告要点
- 触发接口 + 参数 + payload、可访问的内网资源（证据）、利用链、影响面
