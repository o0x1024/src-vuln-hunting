# 文件上传漏洞

## 攻击面
- 头像/证件/附件/导入功能、富文本图片、备份上传、小程序素材
- 后端语言/中间件解析差异（Apache 多后缀、Nginx 解析、IIS 分号截断）

## 绕过思路
### 扩展名层
- 双扩展：`x.php.jpg`、`.php.`（Windows 去点）、大小写 `.PhP`
- 等价后缀：`phtml`/`pht`/`php3`/`php5`/`shtml`（取决于配置）
- 控制文件：`.htaccess`/`.user.ini` 上传（改解析规则）
- 特殊字符：`x.php%00.jpg`（老版本截断）、`x.php/jpg`（部分解析器取前段）

### 内容层
- 图片马：GIF89a 头 + 恶意代码，配合文件包含触发
- Content-Type 伪造：`image/png`
- 前端 JS 校验绕过：直接发请求
- 二次渲染图片马：在 EXIF 注释/尾部插入代码，找渲染不覆盖的位置

## 解析与触发
- 上传后访问路径确认（目录可预测时直接访问）
- 文件包含/图片马配合（详见 lfi-path-traversal.md）
- 存储型 XSS：上传 svg/html 文件名、svg 内嵌脚本

## 最小化验证
- 上传无害测试文件（txt 内容证明可执行即可，如 `phpinfo()` 已禁止时用回显差异）
- 不落地 webshell 驻留、不用真实用户账号上传
- 验证后可删除测试文件，或说明需平台清理

## 报告要点
- 上传接口 + 完整请求、绕过手法、访问 URL、能否代码执行/存储型 XSS 的证据
