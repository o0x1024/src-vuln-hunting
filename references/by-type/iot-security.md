# IoT 设备、协议与固件

触发：授权设备/固件、配网、账号绑定/共享、设备协议或升级链。发现先读 [AI 与设备线索](../discovery/ai-and-devices.md)；小米受理另读 [MiSRC §4.4](../policies/xiaomi-misrc.md)。仅控制自有设备、固件可下载或调试接口存在都不是漏洞确认。

## 建立设备与身份图

保存厂商/型号、硬件修订、固件/区域版本、包哈希/来源、当前配置、支持/EOL 状态及依据。建立账号→家庭/共享角色→设备身份→云服务→本地协议→物理功能的关系。设备 ID 作为资源标识，不自动视为秘密或认证凭证。

每个实验独立记录互联网/局域网/近场/物理接触、是否已配对/授权、所需交互、初始权限和能恢复的状态。准备时用串口/root 观察不等于攻击者拥有该权限；同一局域网可达不能报告成互联网可达。

## 条件专题与最小实验

| 线索 | 检查与对照 | 确认所需结果 |
|---|---|---|
| 绑定、转移、共享/撤销、恢复出厂 | 两个测试身份和获准设备，记录所有权/共享状态与业务规定的撤权时点；从真实客户端调用选一个获准无害能力 | 原本无权或已撤权身份在规定时点后仍被设备/云端接受；排除合法家庭共享、离线延迟和缓存 |
| LAN/BLE/Wi-Fi 等协议认证、重放 | 正常认证会话与一个受控无权/失效会话比较，保留帧、会话状态和 nonce/时间条件；范围只含指定设备 | 实际越过认证/新鲜度边界的数据或安全影响；发现服务/广播/可连接不等于可控制 |
| 固件请求处理器或命令入口 | 离线跟输入→解析→认证→敏感操作；有设备/模拟条件再在许可内观察非持久无害标记 | 可达输入及实际执行上下文；静态危险函数、版本 CVE 或模拟器日志不足以证明真机可利用 |
| OTA、签名、版本/回滚 | 离线核对包来源、信任根、校验路径和目标版本；动态拒绝/接受验证只在批准的隔离副本且有恢复方案时做 | 未授权制品越过真实验签/版本边界；HTTP 下载或明文固件单独不成立，不刷写生产设备 |
| UART/JTAG/调试接口 | 先读授权材料与板级文档；物理连接、拆机等需在明确设备/动作范围内 | 实际获得的权限及保护规则；开放接口但无 shell/敏感数据只记观察，不能自动升级远程漏洞 |
| 摄像、音频、位置、设备 token | 只用无隐私测试场景与标记，核对读取者、数据所属设备和有效权限 | 原本无权的测试身份取得受保护内容；自己的画面/合法日志不构成他人数据泄露 |

云 API、App 与固件缺陷按根因转 [访问控制](idor-access-control.md)、[Android](mobile-android.md) 或对应专题，同一根因不按端数重复计数。硬编码值先区分公开标识、测试值、每设备秘密和生产凭据；不拿发现的真实秘密登录其他设备。

## 执行前提与停止

固件提取、模拟与真机执行分别计覆盖；缺设备可继续离线分析，动态状态为 blocked/未测。模拟器需记录与真机硬件、驱动、配置、权限和固件差异，不能直接外推型号全覆盖。

动作涉及刷写、重置、配对/解绑、锁具、电机、电源、摄像头或告警时，先落实已有许可、无害替代动作及可恢复条件。未获准时只做相应离线/已有证据判读，不执行破坏、持久化、信道占用或资源耗尽。已有最小越界证据即停止该验证，不以扩大设备数量证明严重度。

写入/控制响应超时先查询设备与云端真实状态，不盲重发。预算分别记目标请求、协议帧/连接/配对次数、持续时间和设备动作；新轮次、换工具不能清零。清理含测试绑定/共享、配网与临时配置，按许可恢复；未恢复写交接，不能用删除日志代替清理。

## eMMC 拆卸前检查板上测试点前提

保存硬件提示建议先检查芯片附近测试点，避免直接拆卸损坏设备。以自有硬件记录型号、引脚映射、电压、协议和断电状态，先确认是否真正连到目标总线，再进行可恢复读取验证。测试点可见不证明可以无认证读芯片，板上其他器件与总线争用可能影响结果，未开展物理操作。
