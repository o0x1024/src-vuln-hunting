# 竞态与 TOCTOU

适用信号：单次额度、检查后写入、跨接口共享状态

## 检查与最小实验

先建顺序对照和业务不变量，找操作共享的资源与可能的检查/使用间隙。既考虑同一接口重复，也考虑不同接口触及同一状态；一次请求内部也可能有短暂子状态。

由支持同步的工具调度获准的最小并发（通常两次），记录发出/完成时序与最终权威账本。HTTP/1 last-byte 与 HTTP/2 single-packet 是不同同步机制；单 TCP 连接不代表一个业务动作。工具不支持同步时如实记录，不能靠 Agent 连续调用声称精密并发。

## 证据与反例

多个 200、队列 ID 或短暂 UI 差异不代表重复效果。排除最终去重、异步一致性和正常活动例外；只在最终状态违反不变量时确认。一次未撞中不能证明无竞态。

## Agent 行为

同步突发必须符合并发和操作额度；不套用研究演示的大批量参数，不自动增加压力。成功即停，记录自建资源恢复；没有并发许可时继续离线状态分析。
