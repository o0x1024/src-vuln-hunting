# 越权与访问控制漏洞

## 类型
- 水平越权（IDOR）：改 ID/编号看他人数据（订单、用户、文件、消息）
- 垂直越权：低权限角色调用高权限接口（普通用户→管理员）
- 未授权访问：无登录直接访问管理 API/后台/调试接口

## 发现技巧
- 抓包找带 ID 的接口：`/api/user/1001`、`/order/detail?id=xxx`、`/file/download?fid=`
- 遍历 ID：递增/时间戳/UUID（可预测时）
- 角色切换对比：注册两个账号，A 的请求用 B 的凭证重放
- 隐藏接口：JS 文件里的 admin/api 路由、Swagger 文档、403 改 GET/HEAD/OPTIONS 或加 `X-Forwarded-For`/`X-Original-URL`
- 批量接口：`/api/batch`、`/export?ids=`（批量导出他人数据）

## 验证方式（两个自建账号）
- 用 A 登录拿凭证，访问 B 的资源 ID；能读到即水平越权
- 普通用户 token 调管理员接口；成功即垂直越权
- 未登录调用需鉴权接口；有响应即未授权访问

## 常见防护绕过
- 仅前端隐藏按钮、后端未校验
- 校验用户但未校验资源归属（只验登录不验 ID）
- 方法级鉴权缺失：POST 校验了但 GET/DELETE 未校验
- 静态资源/文件直链：签名 URL 过期校验缺失、防盗链可绕过

## 危害与报告
- 危害取决于可访问数据的敏感度（PII/支付/凭据）
- 报告：两个账号的角色/ID、完整请求对比、读到的他人数据样例（脱敏）、复现步骤
- 验证仅用自建账号，绝不触碰真实用户数据
