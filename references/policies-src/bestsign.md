# 上上签（BestSign）安全应急响应中心 报告处理规则摘要

- 状态: official；置信度: 高
- 来源: https://www.knowsafe.com/help/045617a4b174872b6a5fb24d279a6130.shtml（KnowSafe 平台托管标准全文）（查阅于 2026-10-12）；规则版本/更新: 《SRC漏洞处理和评分标准》V1.0（2020-06-25）
> 公开规则检索摘要，供选题与定级预判；非授权，不保证当前有效，提交前必须核对官方原文。

## 收录范围
上上签电子签约产品线；平台托管于 KnowSafe。

## 等级与奖励
- 等级：严重/高/中/低（完整定义见标准原文）。
- 奖励：礼品商城 Rank 制（40-1000 Rank 档位）。

## 忽略/不收项
- 非安全 Bug、无法重现、无法利用的问题。
- Self-XSS、无敏感操作的 CSRF、无意义异常/内网 IP 泄漏。

## 测试红线
- 修复前禁止向外界传播漏洞信息。

## 报告要求
提交字段：标题 / 等级（低中高严重）/ 分类 / 详情 / 修复方案 + 用户协议。

## 处理流程与时限
待审核 → 已审核/已忽略 → 复查；争议时报告者利益优先。

## 易错点
- 规则托管在 KnowSafe 而非自有域名，检索时易漏。
- V1.0 为 2020 年版本：提交前核对 KnowSafe 项目页是否有更新版。
