# 智联招聘 智联招聘安全应急响应中心（ZPSRC）报告处理规则摘要
- 状态: official；置信度: 高
- 来源: https://src.zhaopin.com/page/view?id=10012（查阅于 2026-10-12）；规则版本/更新: 《ZPSRC安全漏洞处理标准V3.0》（公告列表日期 2022-08-16，详情页 2025-04-11 重发布）；另有《隐私漏洞处理标准V2.0》（2022-04-29）
> 公开规则检索摘要，供选题与定级预判；非授权，不保证当前有效，提交前必须核对官方原文。

## 收录范围
- 智联招聘相关业务：核心业务=招聘主站、招聘企业端、智联招聘 app；一般业务=其他 *.zhaopin.com 资产。
- 智联招聘旗下子公司相关漏洞暂不收取。
- 威胁情报：核心业务/办公网入侵情报、核心产品漏洞情报、重大 0day、大量简历泄露等（另有分级标准）。

## 等级与奖励
- 积分制：1 积分 = 10 RMB；按资产重要性与漏洞影响计分。
- 积分表：核心应用 严重150~300 / 高危50~150 / 中危20~50 / 低危5~20；非核心应用 严重50~100 / 高危25~50 / 中危10~25 / 低危1~10。
- 特别有价值的漏洞给予额外奖励。
- 严重级要点：核心系统权限（命令执行/代码执行/Webshell）；直接导致业务拒绝服务；核心 DB（资金、订单、用户身份、简历内容）SQL 注入与大量核心用户信息/简历泄露；账密校验、核心数据接口、支付逻辑等大量获益逻辑漏洞。
- 高危要点：大量敏感数据遍历、非核心 DB SQL 注入、源码包/硬编码泄露；绕过认证访问管理后台；移动客户端远程代码执行；越权修改简历等重要信息；批量伪造消息、任意账号投递简历/资金消费、批量改密；任意文件读取/删除/创建。

## 忽略/不收项
- 无危害（0积分）：产品功能缺陷、乱码、样式、静态目录遍历、兼容性；Self-XSS、无敏感操作 CSRF、无意义异常信息、内网 IP 泄露、无敏感信息越权、401 钓鱼、横向短信/邮件轰炸；纯用户猜测；浏览器解析本地文件（如 PDF XSS）。
- IE7 及以下由浏览器自身缺陷导致的 XSS 不收；需关闭浏览器默认 XSS 防护才能触发的不收。
- 已公开漏洞/情报不计贡献；内部大规模排查过程中提交的相关漏洞评分减半；刷洞嫌疑不奖励；已知或已失效情报不计分。

## 测试红线
- 务必手工测试，禁止使用扫描器；禁止影响业务正常运行（大量扫描影响业务将采取处置手段，取消奖励）。
- 仅限证明性测试，严禁破坏性测试；无意造成危害应及时报告；测试中的敏感操作（删除、修改等）须在报告中说明。
- 避免攻击性强的 payload：直接修改页面、重复弹框、盗取 cookie、获取其他用户信息；XSS 验证建议用 log；盲打请用 dnslog；不慎使用应立即删除。
- 漏洞修复前禁止公开和传播；未经授权公开给任何第三方不计分并保留追责。

## 报告要求
- 通过 ZPSRC 平台提交（专用邮箱 security@zhaopin.com）。
- 同一漏洞/情报首位报告者计奖；同一域名同类问题前三个有效（3 个以上建议打包提交，可酌情提高评分）。
- 同一账户体系下同一用户弱口令登录不同系统算同一漏洞。

## 处理流程与时限
- 每个漏洞由专门安全人员评估、跟踪并及时反馈（标准未列明具体天数）。
- 争议：邮件 security_team@group.zhaopin.com.cn，按报告者利益优先处理。

## 易错点
- 子公司漏洞暂不收取，别把子公司资产当主站资产提交。
- 通过弱口令、绕过登录认证或未授权访问进入后台/非注册系统后发现的漏洞会被降级处理。
- 白帽主动要求忽略后重新提交，存在被他人抢先的重复风险，需自行承担。
