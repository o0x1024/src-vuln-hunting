# 蔚来 NIO SRC 报告处理规则摘要
- 状态: official；置信度: 高（政策框架层面；平台内评分/奖励细则未公开）
- 来源: https://www.nio.cn/policies/vulnerability-report-policy（查阅于 2026-10-12）；规则版本/更新: 未标注
> 公开规则检索摘要，供选题与定级预判；非授权，不保证当前有效，提交前必须核对官方原文。
## 收录范围
- 官方政策页未列资产明细：蔚来产品与业务系统的安全漏洞，通过 NIO SRC 平台（niosrc.bugbank.cn，漏洞银行托管）提交。
- 平台为漏洞银行企业 SRC 模板（最新公告/排行榜/商城兑换/关于我们），详细收录范围与评分细则需登录平台查看。
## 等级与奖励
- 公开页未公布分值与金额；政策仅承诺"经过核实确认后，我们会通过该平台发放相应奖励"。
## 忽略/不收项
- 公开页未列出；以平台内规则为准。
## 测试红线
- 渗透测试必须满足国家法律法规和 NIO SRC 平台的相关规定。
- 严格遵守测试规范，不得对蔚来造成实际的业务损失和影响。
- 除非获得蔚来授权或依照法律规定，不得向蔚来及 NIO SRC 平台外的第三方披露渗透测试及漏洞的有关信息。
- 不得将上述信息用于善意发现、验证或修复漏洞以外的目的。
- 违反法律法规或本政策对蔚来造成损失或影响的，需承担相应责任，蔚来保留追责权利。
## 报告要求
- 通过 NIO SRC 平台提交；官方按"核实→复现→回应合法举报的漏洞"处理。
## 处理流程与时限
- 官方口径为核实确认后经平台发放奖励，未公开具体时限。
## 易错点
- 公开可得的只有政策框架，定级/奖励细则全部在平台内，选题前先登录平台核对现行规则。
- niosrc.bugbank.cn/rule.html 不存在（404），规则入口在平台登录后导航，勿再盲试静态规则页。
- 未授权向第三方披露是明确红线，修复前公开大概率取消奖励并追责。
