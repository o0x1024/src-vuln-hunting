# 客户端、源码与云资源线索

只有对应材料/环境存在且获准时读取本专题。客户端或云配置的静态提取用于扩充发现图，不代表已验证后端权限、完成客户端安全测试或审计整个云账号。涉及 AI、固件/设备、PC 或车端关系时按 [AI 与设备发现](ai-and-devices.md) 扩充对应分支。

## 客户端与发布材料

先保存材料来源、包哈希、平台、版本、包/应用标识、签名或发布者证据以及取得时间。记录是否能解包、反编译和动态抓包，具体遗漏模块；不从包名相同推导为当前部署。

| 材料 | 提取重点 | 接入方式 |
|---|---|---|
| Android APK、Manifest、资源和获准代码 | 域名/base URL、网络配置、环境分支、深链接/App Links、导出组件、WebView 桥、请求封装与 API | 将组件/代码位置关联接口候选；动态边界另见 [Android](../by-type/mobile-android.md) |
| iOS 提供的包/配置/源码 | Bundle 标识、URL schemes/关联域、网络配置、WebView、请求调用及资源引用 | 包被加密、缺符号或缺设备时标提取限制；动态验证转 [iOS](../by-type/mobile-ios.md)，不将本流程说成完整 iOS 审计 |
| 小程序包、页面配置和正常流量 | app 标识、分包/页面路由、域名、云函数引用、平台登录→业务会话、签名封装 | 平台身份/后端身份分别记录，详见 [小程序](../by-type/miniapp-security.md) |
| 桌面客户端/Electron/扩展的获准发布材料 | 更新端点、环境配置、请求封装、内嵌网页、扩展权限/消息入口和本地桥接引用 | 本地入口与远端服务分开；不运行未知安装器/更新脚本来取配置 |

先静态筛选，再在已授权设备和独立测试账号中抓取一条正常业务路径，核对请求与代码候选的对应。设备代理、证书信任、调试或证书固定相关变更要符合既有设备授权；不能默默修改用户系统。只能读包就只交付静态候选。

跨端比较 Web/APP/小程序的登录、列表、详情、上传、导出等实际业务映射。相同后端路径合并来源但保留客户端版本、身份、参数和方法差异；某一端的正常返回不自动证明其他端覆盖。

## 源码与构建材料

从获准路由注册、OpenAPI 生成物、控制器/中间件、网关配置及 API 客户端提取入口。保留 commit、符号位置、条件编译/功能开关、配置值来源和部署关联；详见 [源码审计](../source-audit.md)。

请求封装中的基址、服务间调用、回调/任务队列、对象存储引用可形成架构边。lockfile/SBOM/依赖清单给出组件候选，不证明版本在线或调用可达。路由在源码存在但没有网关映射时保留“部署可达性未知”。公开仓库的 fork、历史提交和示例要与目标代码分开。

JS、source map、历史 URL 与接口文档中的具体文件或端点，各自保留引用位置和材料版本，再核对当前方法、参数、身份和实际消费者。目录返回 403 不代表目录下每个文件都受相同控制；文件名存在也不代表能读取或含有敏感内容。以已有引用选择少量候选，避免从一个目录拒绝结果生成无依据的递归枚举。

## 云与外部资源

从正常 URL/响应、DNS CNAME、客户端配置、部署/IaC 材料中提取对象存储、CDN、API 网关、函数、镜像仓库、托管身份、消息或数据库的资源引用。保存 provider、服务、账号/项目/区域（未知则空）、资源标识、引用位置及业务用途，不靠名称规则生成大量桶或账号候选。

- 只有公网线索：整理具体资源和服务商关系；已知对象与容器/桶分开。访问指定测试对象也需匹配该资源范围，不从 Web 域名继承云账号权限。
- 有只读云身份且授权允许清单读取：先核对身份、账号/项目、区域和资源类别，再使用宿主提供的只读清单能力，记录权限拒绝、分页与区域缺口。不能把一个区域的返回当全账号资产。
- 只有 IaC/配置：提取声明资源、引用和策略上下文；与部署事实分开，不能称资源已创建或暴露。
- 第三方 SDK/回调：保留集成关系，供应商或其他客户资源维持各自授权状态，不自动验证接管或跨租户访问。

发现配置/身份边界假设再进入 [云安全](../cloud/cloud-security.md)。云清单查询不是读取对象正文、数据库记录或 Secret 的授权，也不包含写资源、计费、绑定域名或注册接管。

交付材料覆盖清单、端点与组件/配置位置、跨端与云关系、动态观察和缺口。候选资源数量、可见资源数量、实际已验证权限分别计数。

格式化/去混淆时保存原文件哈希、版本、来源位置及变换记录，格式化输出的位置要能回到原文件。优先已有本地静态处理，不把私有代码、HAR或令牌粘贴到在线美化站，也不为阅读代码自动执行未知扩展/脚本；显示更易读不证明完整恢复、运行路径或安全边界。

历史反编译工具安装截图只证明某个当时版本在对应机器打开，不能推当前macOS兼容、目标SWF成功反编译或安全边界恢复。提取任务记录获准样本/工具版本、静态输出及遗漏，不从截图“右键打开”继承绕过系统安全检查、下载运行未知JAR或全局改环境的动作；现有静态材料可先供源码候选分析。

## 浏览器存储与代码片段来源

获准浏览器中的sessionStorage/localStorage配置、tabObject、缓存路由表可补静态入口候选；记录origin、键、字段位置、客户端版本及身份。形如#/apiAdmin/...的值先按SPA导航解释，不能直接去掉#当HTTP接口；通过实际路由代码或正常流量关联请求方法、路径与消费者，保留未触发功能的缺口。自己能看到客户端值不证明服务器授予管理权限，也不把存储中的凭据复制到索引。

Gist等公开代码片段与仓库、fork、提交历史分别记录材料所有者、发布时点和部署关联。加入材料来源不等于把整个托管平台加入项目Scope；只读既有获准/公开材料，并按[秘密证据](../by-type/info-secrets.md)脱敏。自有账号打开的私有片段不因可读取就变为公开泄露，不使用其中凭据。

## 发布归档与端点正则的覆盖

Electron材料中的app.asar先作为获准发布归档登记哈希、应用版本、来源和可读成员。提取文件不等于反编译出全部原始源码，打包产物、原生模块、未打包资源与远端后端各有缺口；不运行归档内脚本或未知工具来补齐。将静态引用关联当前路由/请求封装与部署证据，再进入相应安全分支。

仅匹配双引号内以斜线开头、限定字母数字及少量标点的JS正则，会遗漏单引号、模板字符串、连字符、点、绝对URL、拼接和计算路径。命中保存原文件位置与上下文；未命中只表示该规则没找到。少量语法明确的本地合成样本可验证提取器缺口，再结合路由/调用分析补候选，不能用sort后的行数表示所有端点。

## CSP声明与第三方资源候选

从已有CSP提取来源时保留完整指令、enforce/report-only、source expression、scheme/port/path及材料时点。允许的脚本/CDN/IdP域不等于目标拥有的子域，报告端点也不必是页面依赖；同名重复与通配条件保留。图中第三方URL的200/403/404仅是工具当时观察，不能把CSP所有来源自动加入范围或证明目标可达性/漏洞。先静态建立依赖边，不执行“检查所有CSP URL”的外站探测。

## 父域Cookie与浏览器存储的不同边界

把子域脚本、父域Cookie、localStorage、document.domain和CORS分成不同关系：Cookie需核对实际Domain/Path/Secure/HttpOnly/发送条件，localStorage按来源隔离，CORS允许的是特定外源响应读取，document.domain涉及特定DOM同源判断。某处存有令牌不证明兄弟子域脚本可读或令牌可用于另一服务。

2026-10-09核对[MDN localStorage](https://developer.mozilla.org/en-US/docs/Web/API/Window/localStorage)与[document.domain](https://developer.mozilla.org/en-US/docs/Web/API/Document/domain)：后者已弃用，其设置不改变localStorage的来源检查；旧的双方域放宽示例也有浏览器/隔离条件。记录实际两端页面、当前浏览器、执行来源、存储/响应读者与受保护能力，不把旧截图的OOS→P1–P3当通用接管链或范围许可。仅使用自有合成凭据/受控来源观察，不把真实令牌送往另一主机。

## script标签中的JSON与可执行程序

页面script标签内容可能是合法JSON、JavaScript初始化表达式或其他类型数据。保留标签type、原始位置/字节、编码转义和关联消费者；只有合法JSON时做不执行代码的结构解析，表达式/模板混合无法解析就保留未知，不用eval或Function执行页面脚本来恢复对象。

提取到对象/字符串不证明其为当前接口、有效秘密或全部页面数据；继续关联版本、懒加载/动态来源与实际正常请求。未知jefst.py等工具只作为静态能力候选，不安装运行，也不把私有代码上传外部解析站。

## runtime的分块映射与URL重建

[webpack runtime/manifest说明](https://webpack.js.org/concepts/manifest/)将模块解析与懒加载映射放在运行时代码/manifest中（2026-10-09核对官方索引正文）。已有HTML引用的runtime可补未加载模块候选；静态数字ID→名称的映射不是完整文件URL，需跟实际publicPath、名称/内容哈希、扩展名、版本和路径拼接逻辑。源码截图只显示映射的一段时保留遗漏，不能把名字一律加.js并当有效文件。

优先只读解析获准已保存bundle并保留原位置/哈希，结合正常业务加载记录确认少量相关模块。script标签的nonce、timeout或公共CDN基址是加载条件，不自动是秘密、XSS或后端接口；未加载/404也不说明全部逻辑已审。格式化放在受控本地派生副本，不把私密源码贴到在线beautifier，亦不运行bundle、批量下载所有chunk或跨出已授权目的地。

## 反编译字符串提取与有损排除

APK解包/反编译文本用URL正则、sed和grep-v品牌词，只生成字符串候选。保留制品版本、文件/行、原始匹配与每次变换；SDK地址、注释、测试数据、动态拼接、相对路径和实际网络消费者分别核对。按google/auth等子串排除可能丢掉真实登录或业务端点，不等于准确去噪。

同样，JS文本正则不能替代AST或运行时消费者；美化格式也不保证覆盖。对小型获准已有文本比较过滤前后差集、误报与未捕获类型，独立核对归属和当前使用，不自动下载APK、执行反编译工具或访问所有提取URL。

## 脚本声明变量与服务端参数契约

assetfinder/Gau→curl→var正则提取只产生源码声明名候选，不证明它们是URL参数、API输入或可控sink。变量可能仅本地计算/SDK状态；动态、let/const、解构和混淆还会造成漏项。保留URL来源、真实MIME/版本、文件/行、原始声明与每次变换，而不是把变量名直接接成?name=XSS。

图中grep-v .js是未锚定正则排除，后续sed替换的&保留匹配文本，输出格式须按真实命令字节核对，不能按JSfinder题名推集合。已有获准制品中追踪变量到请求构造、服务器契约与实际消费者，再选择单个有依据的字段；brokenJS和演示弹窗不能保证总有XSS，不运行流水线或遍历候选。

## 客户端DNS观察与实际应用请求者

客户端DNS代理只能提供被观察的名称查询，关联应用/进程身份、查询时点、解析器/缓存、后台进程、记录类型和网络配置。名称像CDN不代表当前归属或完整依赖；缓存命中、硬编码地址、其他解析路径和加密DNS会形成不同观察缺口。

先使用获准已有DNS/应用日志按时点关联正常操作，再独立关联HTTP/TLS目标、实际请求方和当前范围。未出现DNS查询不能证明客户端没有通信；看到查询也不能证明应用访问了该服务或获准扫描它。不修改用户全局DNS、启动拦截服务或把候选域批量接入扫描。

## PHP源码参数提取的词法、引用与数据流

针对$_GET的grep/sed串先核对shell引用与正则语法：未正确保护的$可能参与变量展开或正则锚定，混合引号、字符类和多行排版也可能改变模式。源命令不是已验证提取器，不静默改写后宣称所有参数已找到。保留获准源码hash、文件/位置、匹配原文与提取器版本，区分注释/字符串、静态索引、动态键、数组结构及别名。

[PHP $_GET手册](https://www.php.net/manual/en/reserved.variables.get.php)说明它来源于query string，即使HTTP方法不是GET也可填充，且值已urldecode（2026-10-09核读）。读到字段仍需追实际路由/条件、默认值、类型转换、身份权限及最终消费者；不是每个字段都可远程到达或有注入。源码语法解析/数据流与正则候选互补，漏项、不可达路径和不完整制品分别记录；不把输出列表交给线上模糊器或执行来源shell串。

## Burp站点树的JS筛选与采集遗漏

Site map选Script MIME及.js后缀只得到已有采集集合经过过滤的视图。旧图同时隐藏not-found、只选2xx/3xx/5xx并显示task paused，不能称拿到目标全部JS；未导航/懒加载的chunk、无后缀脚本、其他MIME、错误状态和过滤条件之间的关系须独立记录。

保留采集窗口、任务状态、原始树/响应、每个过滤项及视图内外的文件哈希/来源，先辨采集缺失与显示隐藏。实际页面/runtime引用可补候选，但未采集不等于不存在、筛选显示也不证明秘密或现行部署。仅对获准已有记录和离线合成列表核对，不能由截图未勾show-only-in-scope继承跨范围抓取或恢复全站扫描。

## CDN路径命名候选与失效子域的独立状态

目标子域标签与已见CDN脚本路径的对应，可形成有依据的少量邻近文件候选；记录页面引用、构建版本、路径模板及哪些片段来自推导。历史图从多个子域标签推cdn上的JS路径，但解析失败子域不证明它是内部系统，名称像旧项目也不证明对应制品当前存在、私密或可访问。

在获准已保存引用/源码映射中先对照命名规律与版本，分别核对CDN租户/对象归属、缓存/公开发布契约、当前范围、响应内容与真正秘密受众。访问200、JS名字或旧内容不直接等于漏洞；租户隔离/对象不存在是反例。本次不跑随机词表、全子域组合、恢复旧目标或用发现的token调用服务。

## 协作空间导出日志与凭据作用域

SlackPirate旧图持有token、称非admin但可dump用户/access日志，查S3/credential/key、提取消息URL并下载5个文件；“attempting find”与条件文字“If any”不证明每类秘密真实命中，文件名passwordsecret也不证明内容有效。已登录用户可合法读取自己获准资料，非admin标签本身不等于越权。

固定凭据类型/主体、workspace、频道/文件及日志权限、实际返回字段、分页/采集缺口、预期读者与下载副作用；认证有效、导出能力和跨受众秘密披露分别证明。优先提供者给出的少量脱敏日志或合成文件标记，未读来源工具全部实现，不复用图中token、进入workspace、批量读消息/日志或下载真实文件。

把导航URL、客户端deep link和实际API调用分别记录，保留年代、来源、受众/登录状态、权限及响应契约；只在获准合成资料或已有脱敏请求中辨别消费者，不从旧路径批量搜索真实用户、关联个人资料或访问第三方ID查询服务。

在获准已有规则/脱敏日志中分别核对单对象读取、查询/列举、字段写入与跨角色条件，以正常公开数据和严格拒绝为反例。使用最少自建合成对象追身份和权威状态，不导出全库、不跨租户写入、不运行工具或把链接/Logo当完整实现已读。
