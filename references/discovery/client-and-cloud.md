# 客户端、源码与云资源线索

只有对应材料/环境存在且获准时读取本专题。客户端或云配置的静态提取用于扩充发现图，不代表已验证后端权限、完成客户端安全测试或审计整个云账号。涉及 AI、固件/设备、PC 或车端关系时按 [AI 与设备发现](ai-and-devices.md) 扩充对应分支。

## 客户端与发布材料

先保存材料来源、包哈希、平台、版本、包/应用标识、签名或发布者证据以及取得时间。记录是否能解包、反编译和动态抓包，具体遗漏模块；不从包名相同推导为当前部署。

| 材料 | 提取重点 | 接入方式 |
|---|---|---|
| Android APK、Manifest、资源和获准代码 | 域名/base URL、网络配置、环境分支、深链接/App Links、导出组件、WebView 桥、请求封装与 API | 将组件/代码位置关联接口候选；动态边界另见 [Android](../by-type/mobile-android.md) |
| iOS 提供的包/配置/源码 | Bundle 标识、URL schemes/关联域、网络配置、WebView、请求调用及资源引用 | 包被加密、缺符号或缺设备时标提取限制；动态验证转 [iOS](../by-type/mobile-ios.md)，不将本流程说成完整 iOS 审计 |
| 小程序包、页面配置和正常流量 | app 标识、分包/页面路由、域名、云函数引用、平台登录→业务会话、签名封装 | 平台身份/后端身份分别记录，详见 [小程序](../by-type/miniapp-security.md) |
| 桌面客户端/Electron/扩展的获准发布材料 | 更新端点、环境配置、请求封装、内嵌网页、扩展权限/消息入口和本地桥接引用 | 本地入口与远端服务分开；不运行未知安装器/更新脚本来取配置 |

先静态筛选，再在已授权设备和独立测试账号中抓取一条正常业务路径，核对请求与代码候选的对应。设备代理、证书信任、调试或证书固定相关变更要符合既有设备授权；不能默默修改用户系统。只能读包就只交付静态候选。

跨端比较 Web/APP/小程序的登录、列表、详情、上传、导出等实际业务映射。相同后端路径合并来源但保留客户端版本、身份、参数和方法差异；某一端的正常返回不自动证明其他端覆盖。

## 源码与构建材料

从获准路由注册、OpenAPI 生成物、控制器/中间件、网关配置及 API 客户端提取入口。保留 commit、符号位置、条件编译/功能开关、配置值来源和部署关联；详见 [源码审计](../source-audit.md)。

请求封装中的基址、服务间调用、回调/任务队列、对象存储引用可形成架构边。lockfile/SBOM/依赖清单给出组件候选，不证明版本在线或调用可达。路由在源码存在但没有网关映射时保留“部署可达性未知”。公开仓库的 fork、历史提交和示例要与目标代码分开。

## 云与外部资源

从正常 URL/响应、DNS CNAME、客户端配置、部署/IaC 材料中提取对象存储、CDN、API 网关、函数、镜像仓库、托管身份、消息或数据库的资源引用。保存 provider、服务、账号/项目/区域（未知则空）、资源标识、引用位置及业务用途，不靠名称规则生成大量桶或账号候选。

- 只有公网线索：整理具体资源和服务商关系；已知对象与容器/桶分开。访问指定测试对象也需匹配该资源范围，不从 Web 域名继承云账号权限。
- 有只读云身份且授权允许清单读取：先核对身份、账号/项目、区域和资源类别，再使用宿主提供的只读清单能力，记录权限拒绝、分页与区域缺口。不能把一个区域的返回当全账号资产。
- 只有 IaC/配置：提取声明资源、引用和策略上下文；与部署事实分开，不能称资源已创建或暴露。
- 第三方 SDK/回调：保留集成关系，供应商或其他客户资源维持各自授权状态，不自动验证接管或跨租户访问。

发现配置/身份边界假设再进入 [云安全](../cloud/cloud-security.md)。云清单查询不是读取对象正文、数据库记录或 Secret 的授权，也不包含写资源、计费、绑定域名或注册接管。

交付材料覆盖清单、端点与组件/配置位置、跨端与云关系、动态观察和缺口。候选资源数量、可见资源数量、实际已验证权限分别计数。
