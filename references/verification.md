# 阶段 4：验证与留证

## 最小化验证原则
- 能证明危害即可：一个请求包 + 响应 + 说明
- 不做：批量导出、删除/修改真实数据、驻留后门
- 越权/数据类：用自己创建的两个测试账号证明，避免触碰真实用户数据

## 证据留存清单
- 完整请求包（Method + URL + 全部请求头 + Body）
- 完整响应包（状态码 + 响应体关键字段）
- 时间戳（命令/工具输出带时间）
- 截图：URL 可见、关键差异可见
- 操作路径：从登录到触发的每一步
- 复现步骤：可被审核员 1:1 复现的文字步骤

## 影响评估
- 资产重要性：核心业务/边缘业务
- 数据敏感度：是否涉及 PII/支付/凭据
- 利用链：单点漏洞 vs 可组合放大（如 SSRF+内网、越权+敏感数据）
- 自评等级：对照该 SRC 评分标准给参考等级
