# 阶段 1：授权范围与规则（先行）

动手前必须完成，否则后续所有工作都可能是违规测试。

## 必读内容
- 测试范围：域名/IP/C 段/APP/小程序/公众号/云资产列表
- 评分标准：严重/高危/中危/低危定义（决定投入优先级）
- 测试规范：允许与禁止的行为清单
- 时效与流程：测试窗口期、报告提交与审核流程

## 范围确认清单
- [ ] 明确哪些资产在范围内，保存资产清单
- [ ] 明确排除/禁止的资产（第三方、合作方、生产核心系统）
- [ ] 确认是否允许自动化扫描工具
- [ ] 确认是否允许注册/多账号/越权测试及其边界
- [ ] 确认对真实用户数据的操作边界（通常禁止触碰）
- [ ] 截图/存档规则页作为授权留痕

## 红线清单（绝对禁止）
- DDoS / 压力 / 资源耗尽型测试
- 社会工程（钓鱼、诱导员工）
- 对目标的暴力破解（登录口令、验证码爆破需谨慎）
- 批量拖取、导出、篡改真实用户数据
- 删除/破坏数据、上传 webshell 并驻留
- 攻击范围外或第三方系统

## 合规留痕
保存：规则页链接/截图、测试时间窗、所用测试账号与说明、测试范围快照。
