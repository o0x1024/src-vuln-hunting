# 资产、接口与业务面发现

适用：广度覆盖、信息收集，或现有假设缺少入口/业务上下文。目标是建立可追溯的资产—服务—接口—角色—业务关系，并交付实际收集范围与缺口；不是收集尽可能多的 URL。线索验证只补相关分支，报告复核不自动转成在线发现。

## 选择方法

| 当前缺口 | 按需读取 | 预期产物 |
|---|---|---|
| 只有企业/产品名、根域或零散域名 | [被动来源、DNS 与服务](discovery/passive-and-services.md) | 带来源及归属依据的候选资产、服务观察 |
| 已有站点，需要页面、JS、API 与角色覆盖 | [Web 与 API 采集](discovery/web-and-api.md) | 接口清单、参数结构、正常流程及差异 |
| 已有路由、字段或路径线索，需要推导与确认相关入口 | [定向 Fuzzing](targeted-fuzzing.md) | 有来源的有限候选、实际处理证据与下一批依据 |
| 已有客户端包、源码或云资源线索 | [客户端、源码与云线索](discovery/client-and-cloud.md) | 材料版本、提取位置、跨端关系及未分析部分 |
| AI 功能、设备/固件或跨端身份关系 | [AI 与设备线索](discovery/ai-and-devices.md) | 产品/版本、账号与资源、执行/设备关系、静态与动态缺口 |
| 合并来源、恢复或交付 | [发现记录与增量](discovery/records-and-incremental.md) | 观察、候选、队列、来源游标和发现覆盖 |

## 启动与发现循环

先继承 [授权与预算](scope-and-rules.md)、[工具契约](tool-contracts.md) 和已有资产/Run，记录种子及当前可用角色、材料和来源。仅整理已有材料无需等待主动测试权限。信息收集不要求先提出漏洞或证明影响；已知业务价值用于分配预算，未知业务应保留探索机会。

1. **确定本轮范围。** 把用户要求转为必需的资产/来源/角色/功能，以及条件触发项。选定数值预算、采集深度、候选上限、单来源页数、响应体积和时间窗口；无指定数值时继承范围协议的保守起点，把发现与后续验证的请求份额写明，不各领一份预算。
2. **选一项能补缺口的采集。** 优先已有材料、正常流量和未覆盖业务；同一底层数据源的多个包装工具不算独立来源。记录预期新增什么、输出格式和工具的出站/自动动作。
3. **提取并落盘一批观察。** 每条保留来源、原始位置/证据、采集时间、材料或来源观测时间。区分历史引用、静态推导、正常请求和当前服务响应；批次截断、分页失败不能当无结果。
4. **合并候选与关系。** 按 [记录规则](discovery/records-and-incremental.md) 规范化，分别处理归属、授权、可达性与业务用途。第三方引用可以登记，不能自动进入请求队列。
5. **有界确认并扩展。** 仅对动作和目标获准的候选执行 DNS、服务或正常业务读取。新的主机、端口、重定向和文档引用先过范围判断。将新增入口/角色缺口排入下一批；必要前提缺失只阻塞依赖分支。
6. **分流。** 事实足以支持具体边界假设时，转 [业务建模](business-modeling.md) 与 [检测入口](vuln-detection.md)；只有指纹、文件名、隐藏路径时继续作为线索。每批保存游标、消耗、处置与下一步，再决定继续采集或验证。

默认从代表性入口做广度采集，再沿新业务/新身份边界深入。限制日历、筛选排序、分页、随机参数、无限滚动和重复内容路径；发现新业务操作优先于增加同类资源 ID。不要把所有按钮交给自动点击，也不要因“正常导航”忽略请求的业务副作用。

## 主动与被动的边界

离线解析、查询第三方既有索引、DNS 查询、HTTP 访问和端口扫描分别记录。工具按实际模式分类：subfinder 的被动来源查询不等于端口扫描；启用解析、存活确认或串接探测器后需额外核对动作。测绘平台的按需扫描/刷新也不是查询既有索引。来源访问许可、查询配额与目标探测预算分别计数。

先用已有来源减少请求。目录候选来自观察路径、文档、历史记录或实际技术栈；子域候选来自已知命名关系。主动小字典枚举仅在该动作获准且有有限候选集时使用，不默认全端口或大字典穷举。泛解析、软 404、统一登录页先做代表性基线；操作细节见对应参考。

.git、备份或源码暴露先证明最小非敏感样例，不自动完整还原仓库或下载备份。疑似密钥只保存脱敏位置与安全证据引用，不使用生产凭据。接管线索不自动注册资源。发现资产不产生 Scope；已有范围拒绝不能靠更换工具消除。

## 信息收集何时结束

每批比较新增的独立服务、接口结构、角色/状态与业务关系，而非原始 URL 条数。低增量允许停止一个可选来源：先核对它没有报错、截断或分页未完，且与已有来源高度重叠；保存停止理由，不据此宣布全部资产已找齐。

本轮发现完成需要同时满足：约定必需来源及角色/功能已处理；批次观察已保存并合并；待办已执行或有符合任务要求的处置；工具停止、证据与消耗可追溯。每项来源状态和每个必需缺口分别交付。预算触顶且必需工作未完、必需账号/来源缺失或队列仍有必需工作时，本轮停止后标为部分完成；仍在推进其他分支时保持 running。可选来源不可用只记录限制，不能临时把必需项改成可选项。

交付资产/接口/业务关系、已实际访问的角色和状态、各来源/时间窗口、被阻或未处理项、候选假设及下一步。分开统计发现数、授权数、当前观察数和漏洞测试覆盖数。纯信息收集任务可在交付完成后结束，不要求产出 Finding；挖掘任务的发现阶段完成不等于整个 Run 完成。
