# 顺丰 顺丰安全应急响应中心（SFSRC）报告处理规则摘要
- 状态: secondary；置信度: 中
- 来源: https://sfsrc.sf-express.com/（官网为 Vue SPA，规则正文需站内阅读；本摘要来自官方页面的搜索索引快照）（查阅于 2026-10-12）；规则版本/更新: 《SFSRC安全漏洞评分标准V6.2》2024/11/19；《SFSRC安全情报评分标准V3.0》2025/08/16；漏洞收录范围调整的资产【实时更新】2024/01/23
> 公开规则检索摘要，供选题与定级预判；非授权，不保证当前有效，提交前必须核对官方原文。

## 收录范围
- 官方评分标准（V6.1 快照）声明：评分标准适用于"针对顺丰业务有影响的安全漏洞和问题"。
- SFSRC 安全漏洞包括：业务使用的 Web 应用、App 应用、小程序、通用组件或插件的漏洞。
- 官网另设"漏洞收录范围调整的资产【实时更新】"公告（2024/01/23），具体资产清单需站内核对。

## 等级与奖励
- 漏洞等级按对业务系统产生的安全风险分为：严重、高危、中危、低危（另含无/忽略处置）。
- V6.1 快照显示：各等级"对应税后现金奖励"，"积分与人民币兑换比例为1:30"，并按业务系统（核心等）分档；具体分档表需核对原文。
- 奖励发放（用户服务协议）：漏洞/情报经 SFSRC 审核通过后按标准获得奖励，可自行选择兑换税后现金，由 SFSRC 指定的第三方负责报税及发放。
- 威胁情报另有《SFSRC安全情报评分标准V3.0》（2025/08/16），内容需站内核对。

## 忽略/不收项
- 官方标准前言明确"谴责一切利用安全漏洞恐吓用户、攻击竞争对手、勒索的行为"。
- 完整忽略/不收清单未在公开快照中获得，需站内核对。

## 测试红线
- 禁止利用漏洞恐吓用户、攻击竞争对手、勒索（官方标准明文）。
- 官网设有"白帽违规测试事件处置公告"，违规测试会被处置；具体测试规范需站内核对。

## 报告要求
- 通过 SFSRC 平台提交，审核通过后按标准计分/计奖（用户服务协议）。
- 详细报告格式要求未在公开快照中获得。

## 处理流程与时限
- 提交 → SFSRC 审核 → 按标准奖励 → 可选兑换税后现金（第三方报税发放）。
- 具体处理时限未在公开快照中获得。

## 易错点
- 官网为 SPA，规则正文（V6.2、情报标准V3.0、资产实时更新清单）需登录站内阅读；搜索快照只有部分段落，不能当作完整标准。
- "积分:人民币=1:30"来自 V6.1 快照，V6.2 是否调整未确认，不能直接套算奖励金额。
- 收录资产带"实时更新"公告，提交前必须核对最新资产清单，避免提交已移出范围的资产。
