# 合合信息 合合安全应急响应中心（ISRC）报告处理规则摘要
- 状态: official；置信度: 高
- 来源: https://security.intsig.com/index.php?m=&c=page&a=view&id=38（查阅于 2026-10-12）；规则版本/更新: 《合合安全应急响应中心漏洞处理流程及评分标准v1.5》，2025/09/15 发布（历史 v1.2 2021-08-30、v1.3 2022-12-12、v1.4 2024-02-26）
> 公开规则检索摘要，供选题与定级预判；非授权，不保证当前有效，提交前必须核对官方原文。

## 收录范围
- 核心业务：扫描全能王、名片全能王、启信宝、合合信息官网。
- 一般业务：启信慧眼、扫描全能王企业版、名片全能王企业版、TextIn、其他产品或信息系统。
- 第三方业务系统若对合合产生实际危害，按影响范围和程度降级处理。
- 忽略范围明确包含：我司域名指向第三方的非我司系统漏洞；隐私合规、AIGC 内容合规等合规类风险。

## 等级与奖励
- 安全币双表（v1.5）：核心业务 严重300-500 / 高危150-200 / 中危30-100 / 低危5-10；一般业务 严重150-200 / 高危50-100 / 中危10-30 / 低危2-8。
- 1 安全币大约可兑换 10 元人民币奖励。
- 等级说明（按安全币档）：严重 150~500（直接获取服务器/重要客户端权限、RCE、webshell、集群权限凭证 AK/SK/证书；百万条以上重要敏感数据泄露；查看任意用户名片、伪造任意用户登录、账号密码更改）；高 50~200（泄露 5000 条及以上敏感信息（撞库/暴力提交获取的除外）、批量伪造消息/任意账号资金消费/批量改密、绕过认证访问后台/后台弱密码/大量内网信息、越权敏感操作、客户端 RCE、自动传播存储 XSS 与交易资金密码类）；中 10~100（需交互的存储 XSS/重要敏感操作 CSRF、普通越权、内部账号泄露等普通信息泄露、普通逻辑缺陷）；低 2~10（可钓鱼的反射 XSS/URL 跳转、SVN 等轻微泄露、难利用 SQLi/CSRF、垂直短信轰炸/邮箱轰炸）；忽略 0。

## 忽略/不收项
- 无法利用或无危害：无实际影响 CSRF（点赞/收藏/关注）、无法影响他人的本地拒绝服务、Self-XSS、内网 IP/域名/程序路径/logcat 等难利用信息泄露、横向短信/邮件轰炸。
- 利用条件苛刻或无实际危害：静态文件目录遍历/下载、无意义用户枚举、无意义登录接口爆破。
- 我司域名指向第三方的非我司系统漏洞；无关安全的 bug；内部已知或他人已优先提交的漏洞；隐私合规、AIGC 内容合规等合规类风险。

## 测试红线
- 反对和谴责以漏洞测试为借口破坏、损害用户利益（盗取隐私/虚拟财产、入侵系统、窃取数据、恶意传播漏洞）；反对利用漏洞恐吓用户、攻击竞争对手。

## 报告要求
- 平台注册 → 完善个人信息 → 在线提交 → 审核通过获取安全币及积分。
- 合并收取：同一漏洞源（同接口多参数、同一资源 ID 越权）计一个；同系统同类型/利用手段相似或存在利用顺序关系的多个漏洞也按一个处理，应整合为一份报告（拆分提交只对一份加分/升级，其余忽略）。
- 第三方组件 nday：公开 3 个月内且 ISRC 已知晓 → 忽略/驳回不计分；ISRC 未知晓或公开超半年未修复 → 按实际危害定级；需提供参考链接/CVE 编号及可利用证明（POC 证明信息泄露或获取权限）。0day 提供可利用证明后按危害定级。

## 处理流程与时限
- 专项治理：ISRC 不定期对特定类型漏洞专项治理；治理开始前提交的正常评级收取，治理周期内提交的不再收取（审核人员在报告评论提供脱敏凭证：至少含专项治理标题、创建时间）。
- 奖励兑换：每月统计上月 21 日至本月 20 日（含）期间兑换，次月 15 日（含）前发出（节假日顺延）。
- 联系/争议：security@intsig.net。
- v1.5 更新：更新"数据泄露"类定级标准、明确风险接受范围、奖励兑换及发放时间安排。

## 易错点
- v1.5 把启信慧眼/企业版产品/TextIn 划为一般业务（v1.4 及以前部分在企业版名单），按核心业务系数估算奖励会高估。
- 数据泄露定级有明确条数门槛：高危 5000 条起、严重百万条以上；撞库/暴力提交获取的信息不算敏感信息泄露。
- 专项治理周期内同类型漏洞不收，提交前看公告；nday 有 3 个月/半年双门槛，需附 CVE 与可利用证明。
