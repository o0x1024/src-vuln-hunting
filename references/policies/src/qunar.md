# 去哪儿 去哪儿安全应急响应中心（QSRC）报告处理规则摘要
- 状态: official；置信度: 中
- 来源: https://security.qunar.com/（首页“平台简介/提交方式”，直接抓取；公告详情页为 JS 空壳）（查阅于 2026-10-12）；规则版本/更新: QSRC-2013-10 漏洞评分标准（2013-10-13，正文未能直接读取）
> 公开规则检索摘要，供选题与定级预判；非授权，不保证当前有效，提交前必须核对官方原文。

## 收录范围
- 去哪儿产品和业务的安全漏洞（官网首页原文：欢迎广大用户和白帽子提交去哪儿产品和业务的安全漏洞，专人跟进并及时反馈）。
- 重要背景：携程 CSRC 评分标准 V8.0 明确覆盖携程及去哪儿产品和业务（域名包括但不限于 *.ctrip.com、*.trip.com、*.occpay.com、*.qunar.com、双方运营的服务器与 APP），并写明“包括去哪儿SRC”的多平台重复提交限制；V8.1（2026-09-15）正文则仅表述携程产品。去哪儿业务漏洞实际可对照 CSRC 规则体系。

## 等级与奖励
- 官网提及按“QSRC安全漏洞评分标准”定期反馈热心用户和白帽子；贡献榜使用“骆驼币”体系。
- 具体评分表未能公开取得（公告详情页 notice_info.php 由 JS 动态加载，静态抓取为空壳；公告列表仅见 [QSRC-2013-10] 漏洞评分标准，2013-10-13）。

## 忽略/不收项
- 未公开取得。可参考 CSRC V8.1 的不收清单（反射 XSS、URL 跳转、地图 API key、SPF/DKIM/DMARC 等）作预判，但需以 QSRC/CSRC 审核为准。

## 测试红线
- 官网原文：漏洞未修复完成前，请不要公开和传播。
- CSRC 专项公告：暂停接收“去哪儿单一因子验证”的相关越权漏洞（官网公告列表可见标题）。
- 在其他平台（含去哪儿 SRC）提交过的漏洞再提交 CSRC 不计币（V8.0 表述），多平台重复提交受限。

## 报告要求
- 提交方式（官网原文）：① 通过“去哪儿安全应急响应中心”在线提交（推荐）；② 邮件至专用邮箱 security#qunar.com（即 security@qunar.com），邮件主题为“【去哪儿网安全漏洞】”。

## 处理流程与时限
- 官网承诺：专门人员跟进处理，并将结果及时反馈；具体时限未公开标注。
- 公告渠道：/notice.php（当前仅 2013 年评分标准一条公告，平台更新频率极低）。

## 易错点
- 官网为 2013-2014 年代的静态站，评分标准正文藏在 JS 动态加载里，公开渠道基本拿不到现行细则；现行有效标准建议直接对照携程 CSRC V8.1（同集团）并在提交前与官方确认。
- 去哪儿“单一因子验证越权”类漏洞有专项暂停接收公告，勿再提交该类。
- 邮件主题必须带“【去哪儿网安全漏洞】”前缀。
