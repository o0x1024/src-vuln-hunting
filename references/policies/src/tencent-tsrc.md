# 腾讯 TSRC 报告处理规则摘要
- 状态: official；置信度: 高
- 来源: https://docs.qq.com/doc/DSW1Pa0h1SHJ0WWRh（官网导航"奖励规则"指向的腾讯文档，查阅于 2026-10-12）；规则版本/更新: 《TSRC漏洞处理和评分标准》新版于 2020-05-21 00:00 实施（官方公告 TPSA20-18）
> 公开规则检索摘要，供选题与定级预判；非授权，不保证当前有效，提交前必须核对官方原文。

## 收录范围
- 腾讯公司产品与业务的安全漏洞；产品按重要性分为核心产品、重点产品、边缘产品三档，奖励=等级积分×产品贡献系数。
- 官方 PDF 目录显示低危评级新增"游戏漏洞评级规则"。

## 等级与奖励
- 漏洞等级：严重（积分 9-10）、高危（6-8）、中危（3-5）、低危（1-2）；单个漏洞贡献值 = 积分 × 贡献系数。
- 1 贡献值 = 1 安全币 = 5 元人民币；新版下单漏洞基础奖励最高超 1 万元。
- 现金奖励范围（官方 PDF 表，单位元）：核心产品 低 110~220 / 中 525~875 / 高 4020~5360 / 严重 12870~14300；重点、边缘产品依次下移。
- 漏洞报告质量奖：最高 5000 元人民币（以安全币发放）。
- 严重漏洞额外现金奖：上不封顶。
- 荣誉称号按贡献值分档：新手上路 1 / 安全助理 50 / 民间高手 300 / 安全研究员 500 / 高级安全研究员 1000 / 资深安全研究员 2000 / 安全专家 5000 / 高级安全专家 20000 等。

## 忽略/不收项
- 具体忽略条款载于官方文档内《漏洞通用原则》（摘要中可见"详见漏洞通用原则第六条"字样），本次公开检索未取得完整清单；提交前必须在腾讯文档内核对。

## 测试红线
- 以官方文档《漏洞通用原则》为准，公开摘要未完整取得；不得进行影响业务、损害用户利益的测试（行业通行红线，以官方原文为准）。

## 报告要求
- 争取质量奖需：逐步编写漏洞利用流程，为每个动作提供 HTTP 请求包文本、测试思路、详细 Payload、可一键执行复现的 POC 脚本或 Payload 列表与日志，帮助业务快速复现、跟进、修复。

## 处理流程与时限
- 贡献值每日凌晨 2 点更新；设总榜、年榜、月榜。
- 2020-05-21 前旧漏洞按"积分×旧贡献系数"追溯（旧系数：低9/中15/高60/严重120），与新增部分累加；20120520-20200520 旧体系排名保留为"凌烟阁"，另设"特别奖励榜"。
- 翻倍等运营活动仅翻安全币，不翻贡献值。

## 易错点
- 只看等级积分不看产品系数：同积分漏洞在核心/重点/边缘产品上奖励差距可达 10 倍以上。
- 报告描述简单会错失质量奖（最高 5000 元）。
- 规则正文托管在腾讯文档（docs.qq.com），抓取官网只能拿到入口链接；文档以 SVG 方式渲染，纯文本抓取不完整。
