# 宇树科技 USRC 报告处理规则摘要
- 状态: official；置信度: 高（规则全文内置于官方站前端《指引》页）
- 来源: https://security.unitree.com/（查阅于 2026-10-12）；规则版本/更新: 未标注
> 公开规则检索摘要，供选题与定级预判；非授权，不保证当前有效，提交前必须核对官方原文。
## 收录范围
- 所有宇树产品及业务系统的安全漏洞，按三类分表评级：Web 业务系统、产品设备（机器人/四足机器狗）、APP。
- Web 业务系统分级：核心业务（支付、用户敏感信息、敏感订单、机器人/狗的平台或网站）、一般业务（用户运营、物流数据、普通工厂数据、员工信息）、边缘业务（普通运营、普通 OA 信息系统等）；名称疑似宇树的系统由宇树评定是否属于其资产，未列明系统以最终评审为准。
## 等级与奖励
- 官方《指引》分系统评级（人民币；最终按利用难度、业务特点、影响范围等综合评级，宇树拥有最终解释权）：
  - WEB 系统：致命 ¥7000–35000；高危 ¥3500–7000；中危 ¥1400–3500；低危 ¥350–1400；感谢 0。
  - 产品设备（致命示例："可信执行环境（TEE）中的任意代码执行"）：致命 ¥36000–220000；高危 ¥7200–36000；中危 ¥3600–7200；低危 ¥700–3600。
  - APP：独立分表（官方页"产品设备及APP漏洞评级标准"）；站内概览表口径：严重 App ¥2000–12000、高危 ¥1000–3000、中危 ¥100–400、低危 ¥50–100。
  - 注意：站内另有一张概览表（严重 Web ¥3000–5000 / App ¥2000–12000 / 机器人 ¥5000–20000 等）与分系统细则表数值不一致，以《指引》分系统页为准并人工复核。
  - 海外研究员另有美元表（如机器人致命 $1000–5000、Web 严重 $500–1000）。
- 高危口径示例：影响 10 万用户的一般应用存储 XSS/注入；弱口令或认证绕过进入有实际权限/敏感信息的后台；可批量获取 10w+ 用户敏感信息；代码泄露可造成较大危害。
## 忽略/不收项
- "感谢"级 0 奖励：self-xss、无意义点击劫持、无法产生实际影响的 CSRF、无法获取敏感信息的异常信息泄露、暴力破解/暴力注册/恶意下单、其他经验证无法实际利用的漏洞等。
## 测试红线
- 禁止行为：虚构事实、隐瞒真相误导欺骗他人；发表/传送广告及垃圾信息；以测试为借口利用漏洞进行破坏、损害用户利益。
- 不得非法侵入宇树网络、干扰产品服务正常功能、窃取用户数据；不得提供专门用于上述目的的程序工具，不得为他人从事上述危害活动提供技术支持。
- 未经书面许可不得对 USRC 网站反向工程、反向汇编、反向编译。
- 保密义务：未经宇树书面同意禁止向任何第三方披露漏洞名称、分类、所在模块、成因、利用思路、POC 及细节；修复前不得以任何形式讨论；修复后公开讨论需事先同意且在修复 30 天后。
- 必须客观真实描述漏洞影响，夸大影响、煽动用户、恶意制造恐慌将被追究。
## 报告要求
- 高质量报告（1.5 条）：符合要求且高质量的报告可加快评估与奖金发放（客观、真实、可复现）。
- 提交渠道：USRC 平台提交，或邮件 security@unitree.com（站点提供 PGP 公钥 /pgp_key.asc）。
## 处理流程与时限
- 二、处理与反馈流程：2.1 报告阶段（平台/邮件）→ 评估与反馈（官方流程图），具体时限未公开。
- 公开披露：下载填写《漏洞披露申请信息收集表》，连同拟披露完整材料发送 security@unitree.com；审核通过后出具《漏洞披露书面同意函》。
## 易错点
- 终端（机器人/狗）漏洞奖励显著高于 Web（致命上限 ¥220000 vs ¥35000），机器人/TEE 方向优先。
- 概览表与分系统细则表数值不一致，引用前以《指引》页为准。
- 修复后讨论需等 30 天且事先同意；未书面同意披露属明确红线。
