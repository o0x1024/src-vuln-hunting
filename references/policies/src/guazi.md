# 瓜子 瓜子安全应急响应中心（GZSRC）报告处理规则摘要
- 状态: secondary；置信度: 中
- 来源: https://www.vulbox.com/news/detail-180（漏洞盒子转载官方《瓜子安全应急响应中心外部漏洞奖励规则V1.0》；官方站 security.guazi.com DNS 不解析）（查阅于 2026-10-12）；规则版本/更新: 外部漏洞奖励规则V1.0（未标注发布日期，转载版本）
> 公开规则检索摘要，供选题与定级预判；非授权，不保证当前有效，提交前必须核对官方原文。

## 收录范围
- 评分标准仅适用于车好多集团所有产品和服务；目前仅收集以下域名：*.guazi.com、*.maodou.com。
- 业务分级：核心系统（业务系数 2）=瓜子二手车直卖网、毛豆新车网、车速拍、金融业务、向日葵、检瓜子及智能视频管理系统的 WEB 和 APP；一般系统（系数 1）=瓜子内外部业务支撑系统（WEB+APP）；边缘系统（系数 0.5）=办公类 IT 系统及除核心/一般外的业务系统。

## 等级与奖励
- 漏洞评分参照 CVSS 3.0 判定；漏洞积分=单个漏洞评分×权重系统×业务系统；1 积分=1 元。
- 覆盖类型：Web 安全、移动端、系统网络、业务安全、通用软件漏洞等；最终定级以对业务本身的影响为评价标准。
- 威胁情报分级：严重（核心系统/办公网入侵情报、重大 0Day、大批量用户敏感信息泄露、重大影响事件）；高危（非核心业务入侵、重大新型病毒木马蠕虫、数据查询外挂等威胁组织活动情报、内部机密泄露）；中危（行业新型攻击技术/数据窃取方法、新型可利用工具平台如外挂/扫单程序、营销活动作弊与业务规则绕过）；低危（威胁组织基础信息、涉瓜子舆情谣言）。

## 忽略/不收项
- 无法重现的漏洞（审核者多次确认无法重现）。
- 内部已知、正在处理的漏洞，包括已在其他平台公开通用的、白帽子或内部已发现的。
- 无业务安全影响的 BUG（功能缺陷、页面乱码、样式混乱等）。
- 无法利用的漏洞：Self-XSS、无敏感操作的 CSRF、无敏感信息的 JSON 劫持、无意义的源码泄露。
- 涉及第三方系统、不属于瓜子二手车业务的漏洞。

## 测试红线
- 严格保密已提交的漏洞，如泄密一经发现撤回所有奖励。
- 以测试漏洞为借口，利用漏洞损害用户利益、影响业务运作、盗取用户数据等行为不计积分，并保留法律行动权利。
- 车好多集团员工不得有任何借助平台牟取私利的行为。

## 报告要求
- 报告尽量详细规范：漏洞详情、原理、利用方式、修复建议可酌情加分；必须证明存在且可利用，未提供 POC/exploit 或缺少详细分析将直接影响评定。
- 同一漏洞首位报送者计贡献值和积分；报告网上已公开漏洞及安全部已知问题不计。

## 处理流程与时限
- 流程含提交、审核、修复、完成等阶段；完成阶段 GZSRC 更新漏洞处理状态并关闭漏洞（全文仅部分流程段落可见，具体时限未标注）。
- 重复规则：同一漏洞一个月内重复上报忽略；超过一个月再次上报按新漏洞处理（业务方已排期修复中的除外）；官方发布新版本修复后旧漏洞忽略，但非安全修复原因导致新版不存在的按新漏洞处理。
- 通用漏洞：同一漏洞源引发的多个漏洞计 1 个，按最高级别奖励标准执行（同一 JS 多个 XSS、同一发布系统多页面、框架整站、泛域名、同一 URL 多参数相同问题等）。
- 争议：联系微信群或邮件 GZSRC@guazi.com；按报告者利益优先处理，必要时引入外部人士共同裁定。

## 易错点
- 官方站 security.guazi.com DNS 已不解析，现行规则状态不明；漏洞盒子转载的 V1.0 无日期，奖励数值可能已调整，提交前务必向 GZSRC 邮箱确认现行版本。
- 收录域名仅 *.guazi.com 与 *.maodou.com，车好多其他品牌资产不在列。
- 一个月内重复上报直接忽略，勿反复催交同一漏洞。
