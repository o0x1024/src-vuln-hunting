# 焦点科技 焦点安全应急响应中心（FSRC）报告处理规则摘要
- 状态: official；置信度: 高
- 来源: https://security.focuschina.com/home/announcement/view/id/2.html（查阅于 2026-10-12）；规则版本/更新: 《FSRC安全情报定级及积分规则》公告编号 FSRC-2024-05，修订记录至 V7.6（页面落款 2026-10-09；V1.0 2016-04-05 起）
> 公开规则检索摘要，供选题与定级预判；非授权，不保证当前有效，提交前必须核对官方原文。

## 收录范围
- 白名单制：FSRC 仅接收下表产品安全情报，非白名单产品原则上不接收（确有帮助可给贡献值参与年度排名，但不提供奖金）。
- 核心应用（系数10）：中国制造网英文版 made-in-china.com（登录、注册、会员中心VO、询盘、RFQ、重要信息展示页、批量邮件系统）；新一站保险网 xyz.cn（会员中心、投保、登录、注册、重要信息展示页）。
- 一般应用（系数4）：中国制造网英文版多语言/数据罗盘/展示厅；新一站理赔业务；百卓轻云 www.abiz.com（仅接受批量涉及用户敏感信息的漏洞，且仅 www.abiz.com、erp.abiz.com、appservernew.abiz.com）；中国制造网中文版 cn.made-in-china.com（仅批量敏感信息漏洞，会员中心）；领动云平台（仅批量敏感信息漏洞，仅 www.leadong.com、website.leadong.com、media.leadong.com、a0.leadongcdn.com、a0.leadongcdn.cn、en.*.tw.ldyjz.com）；焦点科技内部系统 MIC 销售系统中涉及合同等敏感信息的业务。
- 边缘应用（系数1）：各表"未列出的其他业务"；焦点科技官网与 FSRC 官网；统一认证系统；MIC 销售系统其余业务。
- 明确不接收：新贝易保及旅行箱相关漏洞（FSRC-2022-08）；非焦点可控产品（CMS、供应链软件、第三方平台自身漏洞）请提交对应厂商或 NVDB，FSRC 不再接收。
- 部分产品限制详见 https://security.focuschina.com/home/announcement/view/id/657.html 。

## 等级与奖励
- 漏洞按危害分严重/高/中/低/无（忽略）五级；以危害为唯一评级标准，不局限于漏洞类型。
- 贡献值表（系数×等级）：核心(10) 严重90-100 / 高危60-80 / 中危30-50 / 低危10-20；一般(4) 36-40 / 24-32 / 12-20 / 4-8；边缘(1) 9-10 / 6-8 / 3-5 / 1-2。
- 安全币表：核心(10) 严重3600-4000 / 高危1200-2400 / 中危400-800 / 低危100-200；一般(4) 1400-1600 / 500-1000 / 200-300 / 100；边缘(1) 300-400 / 100-200 / 100 / 无。
- 边缘应用低危：只发贡献值不发安全币，且不确保按时修复。
- 威胁情报：严重 9-10 贡献值 / 1800-2000 安全币；高危 6-8 / 600-1200；中危 3-5 / 100-500；低危 1-2 / 20-80；忽略 0/0；对焦点业务影响大的情报最多 5 倍奖励。
- 严重级示例：关键 DB SQL 注入、百万级用户敏感信息泄露、核心应用服务器 RCE/webshell、篡改核心官网主页、无限制刷取可兑换现金积分的逻辑漏洞。
- 安全币兑换礼品，未使用不过期；月度/年度奖励关注微信公众号 focus_security。

## 忽略/不收项
- 无危害：无关安全 bug；无法利用的"漏洞"（无意义扫描器报告、Self-XSS、无敏感信息 JSON Hijacking、无敏感操作 CSRF、内网/后台 IP 泄露但无法进入、example 默认 demo 未删除、无敏感信息 SVN 泄露、程序路径信任问题、无法利用的绝对路径/phpinfo/logcat 等）；没有证据的推测；未提供协助验证信息的撞库；直接依赖用户安全意识的漏洞（401 钓鱼、只能钓鱼的 URL 跳转、点击劫持、上传 doc 宏病毒等需用户下载执行的文件）；与焦点无关的漏洞；FSRC 公告暂时不接受的域名漏洞。

## 测试红线
- 反对以漏洞测试为借口进行破坏、损害用户利益（盗取隐私/虚拟财产、入侵系统、窃取数据、恶意传播漏洞）；反对利用漏洞恐吓用户、攻击竞争对手。
- 获取管理员权限后须谨慎操作，造成重大影响不计分并保留追责权利。
- 焦点集团及所属公司员工不得参与漏洞奖励计划。

## 报告要求
- 反馈漏洞时请提供 PoC/EXP 及漏洞分析，否则可能直接影响评分和奖金；完整流程有助于提高评分。
- 同一情报第一个报告者得分；网上已公开的不计分；同一处问题产生的多个漏洞计一个；开源/第三方插件同类型漏洞仅收一个且不保证处理时间。
- 已复测问题仍存在可再次提交并再次计分。

## 处理流程与时限
- 预报告（授权生成账号）→ 报告（状态：已提交）→ 处理（1 个工作日内跟进评估并给出结论；3 个工作日内与业务共同计分并发放奖金）→ 修复（严重/高危 1 个工作日、中危 3 个工作日、低危 15 个工作日；客户端按版本）→ 复测 → 完成（每月上旬发布致谢公告；礼品下月月初寄出）。
- 申诉：security@focuschina.com 或官方 QQ（3281160995，群 605800516），必要时引入外部专业人士裁定。

## 易错点
- 白名单外资产提交没有奖金（只有贡献值）；提交前逐条核对最新接收范围表。
- 百卓轻云、中文站、领动只收"批量涉及用户敏感信息"的漏洞，单条信息类问题大概率不收。
- 边缘应用低危无安全币；修订历史显示范围频繁调整（V6.x-V7.6 多次暂停/恢复业务），以页面当前表格为准。
