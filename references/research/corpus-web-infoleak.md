## 判定为有效的关键

- **必须有数据落点**。只有端点存在、只有告警文案、只回显路径 → 上限低危（2501、2406、2529），更多的连等级都没有（22831、10314）。能直接读到他人数据、可用凭据或他人内容，才进入中危以上。
- **「展示差异」是最强证据形态**。站内只显示头像，接口返回职业/地点/微信昵称/性别籍贯（2248、2249、2251）；或 403 响应仍带创建者真实姓名与头像（24517）。先截正常入口能看到什么，再截接口多给了什么，判定不依赖个人对「敏感」的主观定义。
- **量化的四件套**：条数、容量、字段清单、数据新鲜度。语料中的量级样本：194,061 个对象 / 451.6 GiB / 最新数据距今数日（24614）；19,911 + 151,861 + 35,251 三张表（23238）；手机号前缀可规律性批量（10873）。给出「多少条、多大、哪些字段、多新」比给一条响应强得多。
- **证明能力而非样本**。能证明可枚举、可翻页、可签名任意 key（7990 的 `marker` 翻页、23908 的空 key 签名、11349 的 cookie 递增）即成立，不需要把全量数据取下来。
- **「预期公开」三问**：① 公开的是不是这个东西（24644 自证：模板中心公开的应是预览，而接口返回完整可编辑配置与 `dbAppInstanceId/dbFileId/sourceFileSid` 等内部引用）；② 拿到的是客户端标识还是服务端秘密（11158 的 `accessid` 被忽略，2331/2548 的 key 与数据库账号成立）；③ 这条结论是否随口径漂移（内网 IP 在 2020 批量照收 43 条，2025 后同类无等级）——报前先看当年公告与本族最近结论，不要拿旧结论套新口径。
- **按更强的类型归属报**。同一事实写成「越权 / 未授权访问 / 任意文件读取」比写成「信息泄漏」等级更高、更容易被受理：11349（越权，高危）、12045/12074（越权，中危）、24167（文件读取，中危），而 24163/24166 同族只写「信息泄漏」即无等级。
- **去重自查先做**。同资产同接口可能已被他人提交（24163/24166 与 24167 是同一 `yuncc/download` 模块的 `path` 参数；24517 与 22834 同属文档业务），重复即归零。判断依据是「同一根因 + 同一资产」，不是标题措辞。

## 证据形态

- **截图密度即交付质量**。严重案例图片数 10–17 张（23238 17、24614 13、23908 12），低危多为 0–1 张。语料用「有多少张可复核的图」隐性表达证据完整度：入口页、抓包、请求、响应、数据样本、统计口径各一张。
- **双账号对照**。受害者侧完成创建动作（新建知识库、新建待办、上传附件、发文章），攻击者侧发请求（23842、23790、12074、10873、23863）。单账号只能证明「接口返回了东西」，双账号才能证明「返回了别人的东西」。
- **请求与响应成对，关键字段框选**。响应不整段贴出，只给字段名 + 少量样本值 + 计数；全量数据不入报告（23238 明写「漏洞提交后将删除敏感数据」）。
- **最小化声明与操作边界分栏写**。24406、24717 明写「仅使用本人账号与本人数据、未枚举、未获取其他用户数据、未联系签发方」；12767 在提交前先声明「先提交报备，防止被误判为攻击事件」。这类声明本身就是可信度的一部分。
- **可被第三方重放**。复现步骤写到「用哪个账号、点哪个入口、改哪个参数、看到哪一行」，使受理方能用自己的账号重跑一遍（23842、23863 的步骤粒度即如此）；只贴一条请求而无前置条件与页面入口的描述，在语料中多为无等级。
- **等级自评不等于结论**。23863 自评「中高危」而语料为「中危 / 已忽略」，说明自评不能替代论证；把受影响数据、受影响主体、可枚举范围写实，等级交给受理方判定。
- **脱敏**。姓名、手机号、身份证、银行卡、桶名、内网 IP、aksk 一律打码或写 `<redacted>`；凭据只保留「位置 + 类型 + 不可逆指纹」，不复述明文（本档即按此处理）。
- **不能算证据**：目录扫描得到的路径列表本身（10089 需再跟一条能直接打开的文件）、只有 base64 串（6564 必须给出解码后的节点类型与用途）、凭据外带验证（不得用真实凭据接管服务或补测账号）。

## 可复用检查清单

1. 先确认资产归属（证书、备案、页面版权、官网引用、抓包来源），归属不明先问，不动手（6604 即以证书确认归属）。
2. 入口三件套走一遍：可见页面 → 抓包接口 → 拉取 async chunk 搜 `api|/v[0-9]/|export|admin|list|download`，找「前端有调用、页面无入口」的接口（7079、23238 均由此进入）。
3. 对每个接口列全字段，与页面实际展示字段做**差集**，差集即候选泄漏点（2248、2249、2251）。
4. 找可控参数并分类：`id|uid|corp_id|group_id|drive_id|key|path|sid|t=`；先本人两账号互测，再决定是否需第三账号（23913、24008、12045）。
