# 阶段 6：运营与全流程检查清单

## 持续运营
- 盯新上线业务：新业务是漏洞高发区（上线期抢挖）
- 关注 SRC 活动：月度冲刺、双倍积分期
- 关注审核状态，被驳回快速补充证据
- 复盘：统计提交类型/被拒原因/高分报告，迭代方法论

## 全流程检查清单

### 规则阶段
- [ ] 读透范围/评分/规范，保存留痕
- [ ] 确认红线行为清单，测试账号就绪

### 资产阶段
- [ ] 子域名 + 接管检测完成
- [ ] 端口/服务指纹完成
- [ ] 目录/接口枚举完成（含 .git/备份/swagger）

### 检测阶段
- [ ] 业务逻辑（越权/支付/验证码/竞态）优先覆盖
- [ ] 认证与未授权访问覆盖
- [ ] 经典 Web 漏洞按指纹针对性测试
- [ ] 组件 CVE 与基础设施未授权检查

### 验证与报告阶段
- [ ] 每个漏洞有完整请求/响应包 + 时间戳 + 截图
- [ ] 复现步骤可 1:1 重放
- [ ] 报告含影响分析与修复建议
- [ ] 确认漏洞未被他人提交过

## 原则速记
合规 > 资产面 > 逻辑漏洞 > 经典漏洞 > 组件 CVE
证据 > 速度；质量 > 数量。
